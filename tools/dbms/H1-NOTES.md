## 5. 「写しの頭」を行列から直に読む述語（本命）

BMS の展開は「悪い部分を上昇させて写す」。上昇は**行 0 に効く**ので、
もとの根 `(0,0,0)` は写しの中で `(k,0,0)` になる。写しをもう一度写せば
その親もまた `(k',0,0)` である。よって

    copy_head(Mo, j)  <=>  Mo[j] が「x w」の柱 (k,0,0) k>=1 で、
                           行 0 の親をたどると根 (0,*,*) まで
                           「x w」の柱だけで届く

これは**行列から直に読める**（`st` を持ち回らない）ので写しに同変。

実例 `A3<4>`（`|` は写しの切れ目）:

    (0,0,0)(1,1,1)(2,1,0)(2,1,0) | (1,0,0)(2,1,1)(3,1,0)(3,1,0) | (2,0,0)... | (3,0,0)...
     ^根                            ^写しの頭                      ^写しの頭     ^写しの頭

`(1,0,0)` の親は `(0,0,0)`、`(2,0,0)` の親は `(1,0,0)`、… と鎖になる。

C2 が壊れる 5 例（<=6 列）は全部 A3 / A4 に柱を 1 本足したものだった:

    (0,0,0)(1,1,1)(2,1,0)(3,1,0)(1,1,0)(1,1,0)  n=3

追いかけると、`copy_head` 以外にも**写しに同変でない道具**が 3 つ見つかった。

1. `closes_unit(nxt) = nxt[0] <= 1 and nxt[2] == 0`
   写しの中ではアンカー `(1,1,0)` が `(k,1,0)` に化ける（行 0 だけ上がる）ので
   `nxt[0] <= 1` が当たらない。正しい読みは「次の柱が**いまの写しの根の直下**」:

       top_level(Mo, j) <=> par0(Mo, j) が根か写しの頭
       closes_top(Mo, off, nxt) <=> nxt is None or (nxt[2]==0 and top_level(Mo, off+1))

   `closes_chead` はこの特別な場合（次が写しの頭そのもの）である。
   旗 `closes_top`。5 例のうち 2 例が直る。

2. `copy_head` の親の鎖が**アンカーで切れる**。
   `(0,0,0)(1,1,1)(2,1,0)(2,1,0)(1,1,0)` の写しの頭は `(2,0,0)` で、その親は
   アンカー `(1,1,0)`（「x w」の柱ではない）。アンカーも「行 1 の加算項の頭」
   なので鎖を通すべき（旗 `chead_anch`）。

3. `hi_block` の起点 `b` が写しをまたぐ。
   `b = 最後の (a,a,z) a>=1` は写しの中では**もとの (1,1,1) のまま**なので、
   写しの外の行 2 を数えてしまう。起点を「写しの頭の次の柱」まで進めると直る
   （旗 `hi_chead`。写しの頭が無い行列では**無変化**なので安全）。

`closes_top + chead_anch + hi_chead + wch_chead + p0deep` の 5 本で
**5 例のうち 3 例が直り、残り 2 例**（`...(1,1,0)(2,1,0)` の形, n=3）。

## 11. 最終形（旗 `V14['h1']`, 5 条項）

`Mo` と `off` と次の柱だけで決まる（`st['prev']` を新たに持ち回らない）。

    term_top(Mo, j)     項の頭か。根 (0,*,*) / アンカー (1,1,0) /
                        根の写し (k,0,0) / アンカーの写し (k,1,0)
    copy_head(Mo, j)    写しの頭 = (k,0,0) で親が term_top
    top_level(Mo, j)    いまの写しの根の直下 = 親が根または写しの頭
    closes_top(...)     closes_unit の写し版（次が写しの根の直下なら閉じる）
    hi_block2(m, x)     hi_block の起点 b を「写しの頭の次の柱」まで進める
    wchain_head         鎖の頭が写しの頭なら根と同じ（鎖が切れる）
    p0deep_ok(...)      prev == 0 の枝: 深い <=> nxt[0] >= p[0]
                        or（前にアンカー無し and nxt[1] >= 1）

もとの行列（写しの頭が 1 つも無いもの）では `term_top` は「根とアンカー」、
`closes_top` は `closes_unit`、`hi_block2` は `hi_block` にそのまま戻る。
だから**シートは 1 行も動かない**。
