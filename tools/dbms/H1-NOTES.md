## 5. 「写しの頭」を行列から直に読む述語（本命）

BMS の展開は「悪い部分を上昇させて写す」。上昇は**行 0 に効く**ので、
もとの根 `(0,0,0)` は写しの中で `(k,0,0)` になる。写しをもう一度写せば
その親もまた `(k',0,0)` である。よって

    copy_head(Mo, j)  <=>  Mo[j] が「x w」の柱 (k,0,0) k>=1 で、
                           行 0 の親をたどると根 (0,*,*) まで
                           「x w」の柱だけで届く

これは**行列から直に読める**（`st` を持ち回らない）ので写しに同変。

実例 `A3<4>`（`|` は写しの切れ目）:

    (0,0,0)(1,1,1)(2,1,0)(2,1,0) | (1,0,0)(2,1,1)(3,1,0)(3,1,0) | (2,0,0)... | (3,0,0)...
     ^根                            ^写しの頭                      ^写しの頭     ^写しの頭

`(1,0,0)` の親は `(0,0,0)`、`(2,0,0)` の親は `(1,0,0)`、… と鎖になる。

# 課題 H3（A1 の像の自由度 / closes_top の 36 本 / 縮約の地図）2026-08-28

## 19. A1 の姿を数字で押さえた

    conv3(A1<n>) = 接頭 7 本 + block_1 + ... + block_{n-1}
    f(A1)<m>     = 接頭 7 本 + block_2 + ... + block_m
    block_k = (k+1,k,0)(k+2,k+1,1)(k+3,0,0)(k+4,1,0)(k+5,2,1)

**同じ本数のブロックだが、始まりの番号が 1 つずれている。** これが族 β の正体。
`conv3(A1<n>)` は `f(A1)<n>` より小さいので **C2 は立っている**（実測 0）。
破れているのは ImgClosedT だけ。

* 接頭 7 本は**動かせない**: `(0,0,0)(1,1,1)(2,0,0)(3,1,1)` は**シート行 337**
  にあり、像は `(0,0,0)(1,0,0)(2,1,0)(3,2,1)(4,0,0)(5,1,0)(6,2,1)`。
* `conv3(A1)` は**必ず行 2 = 1 の柱で終わる**（A1 の末尾 `(1,1,1)` の本体だから）。
* 順序の窓: 直前の行列 `(0,0,0)(1,1,1)(2,0,0)(3,1,1)(1,1,0)(2,2,1)` の像
  `接頭 + (2,1,0)(3,2,1)` より**大きく**なければならない。
* **`N<1> == conv3(A1<2>)` を満たす DBMS 標準形は 0 個**（尾を全数探索）。
  つまり `B = A1<m+1>` という組み合わせは、`conv3(A1)` を何にしても成り立たない。

### 19b. **A1 の像は動かしても救えない**（全数で確かめた）

`conv3(A1)` として構造的にありうるのは `接頭 7 本 ++ 尾`（尾は 1〜3 列、
最後の柱は行 2 = 1）で、順序の下限 `接頭 ++ (2,1,0)(3,2,1)` より大きいもの。
さらに「すでに他の行列の像になっているもの」を除くと **候補は 81 個**。

    81 個ぜんぶについて N<1>, N<2>, N<3> の逆像を探した（d2b3 ＋ 誘導つき DFS）
    -> **0/81**。どれも m<=3 のどこかで逆像を持たない。

別の見方でも同じ:

* `N<1> == conv3(A1<2>)` を満たす N は **0 個**（B = A<m+1> の対応は不可能）
* `N<m>` が m<=5 でぜんぶ `{conv3(A1<n>) : n<=8}` に入る N も **0 個**

**チームリードの案 `接頭 ++ (2,1,0)(3,2,1)` は使えない。** それは
直前の行列 `(0,0,0)(1,1,1)(2,0,0)(3,1,1)(1,1,0)(2,2,1)` の像そのもので、
採ると順序が壊れる（衝突する）。

結論: **A1 は「像を動かす」では直らない。**`conv3(A1<n>)` の側（写しのブロックを
block_1 でなく block_2 から始める＝ H2 の sibbody）しか道がなく、そちらは
縮約と衝突する。

シートに載っていない行列は gen<=5 の **1018 個中 893 個（87.7%）**。
自由度は大きいが、シートの 125 個が設計を縛っている。

## 20. `closes_top` の撃ちすぎ 36 本は**分けられなかった**

    closes_top が新しく発火する site 3970 個
      このままで正しい 3934（99.1%） / 止めるべき 36（0.9%）

素性 48 個（行列から直に読めるもの＋写しの頭の鎖の長さなど）で fp=0 の連言を
全部集めても、**貪欲 2 選言で 24/36 まで**（`!prev0 & wch` ＋
`nbr0 & !prev0 & pv2_z`）。しかもどちらも `st['prev']` を使うので**同変でない**。

36 本の形は非常に均一:

    p = (k,1,0) が写しのブロックの**末尾**、nx = (k',0,0) が次のブロックの頭、
    nx2 = (k'+1,1,1)。off は 17 か 23（24 列 / 30 列の行列）。

**同じ行列の中で、同じ形の site が正しかったり誤ったりする**（off=11 は正しく
off=17 は誤り）。試した構造素性はどれも分けない:

    写しの頭の鎖の長さ    3: 正 2196 / 誤 24   4: 正 1270 / 誤 12   5 以上: 誤 0
    nx が最後の写しの頭か  はい: 正 2143 / 誤 24   いいえ: 正 1791 / 誤 12
    nx から末尾までの長さ  6: 正 1416 / 誤 24   12: 誤 12

つまり**局所の形では決まらない**。素性を 66 個まで増やしても（写しの頭の
個数・前後の個数・ブロック長・末尾までの長さ・鎖の長さ…）**貪欲 2 選言で
24/36 が上限**で、しかも両方 `st['prev']` を使う（同変でない）。

**ラベルが偽ではないことは確かめた。** 代表例

    A = (0,0,0)(1,1,1)(2,1,0)(3,2,1)(4,0,0)(2,1,0)(1,1,0)
    E = A<4> （24 列）,  (conv3 A)<3> は 22 列で conv3(E) と同じ長さ、ちがい 1 本
    off=17 src=(4,1,0) nxt=(3,0,0)  got (5,1,0) / want (5,2,0)

`m <-> m+1` の対応は正しい（`<2>` も `<4>` も長さが合わない）。
同じ行列の中で**同じ形の site が 3 つ**（off=5, 11, 17）あり、
5 と 11 は浅くて正しく、17 だけ深くなければいけない:

    E の写しの頭 = 6, 12, 18   同形 site = (5,→6) (11,→12) (17,→18)

`closes_top` 自体は 99.1% 正しいので、この 36 本は当面そのままでよいと判断する
（優先度は下げる。**局所の述語では届かない**という結論）。
