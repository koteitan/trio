## 逆算のやり方（F2 の `w2.py` step1..step5 と同じ）

1. 破れた対 `(A, m, T)` について `T = conv3(A)<m>` を出す。
2. `T` の**接頭辞**が `conv3` の像になるような標準形 `B` の候補を
   `inv3.d2b3(T)` と誘導つき DFS（`imgfast.search2`）で探す。
   見つからないときは「`T` のどの柱が像として有り得ないか」を特定する。
3. その柱を出したのは `conv3` のどの分岐か（`rows3.conv3` に print を刺す）。
4. その分岐が見ている窓を広げる／条件を足すと直るか、**最小の条項**を書く。
5. 旗 `V14 = {...}` に入れて 7 つの土俵を全部測る。**1 つでも悪化したら捨てる**。

| | シート行 | conv3(A) がシートと一致 |

A<n>（展開したもの）は 4 つとも**シートに 1 行も載っていない**。
つまり **`conv3(A)` は正しく、直すのは `conv3(A<n>)` の側**。確定。

## 2. 族 α（A3, A4）— 柱 1 本の行 1 が 1 だけ浅い

長さは**ぴったり一致**する。ちがうのは写しごとに 1 本だけ:

    A3, m=2: |f(A)<m>| = |f(A<m+1>)| = 11、ちがう柱 1 本
             [9]  f(A)<2>   = (5,2,0)      <- 正解
                  f(A<3>)   = (5,1,0)      <- conv3 がこう出している
    A3, m=3: ちがう柱 2 本  [9] (5,2,0)/(5,1,0)  [14] (6,2,0)/(6,1,0)
    A4 もまったく同じ位置・同じ値。

**正解は深い側 `(k,2,0)`。** 位置は「写しの 4 本目」。
これは分岐列 `(a,1,0)` の `base_s`（浅い）／`base_d`（深い）の選択そのもの
（`rows3.conv3` の `if is_branch(p) and base_s != base_d:` の枝）。
**写しの中に入ったとき、深い側を取り損ねている。**

`SandwichU` の 2 個（<=7 列）も v13 では**同じ病**である:

    (0,0,0)(1,1,1)(2,1,0)(3,2,1)(3,2,0)(3,1,0)(1,1,1)  n=1 の柱 7
       f(A<1>)  = (5,1,0)      (f A)<2> = (5,2,0)
    (0,0,0)(1,1,1)(2,2,1)(3,2,1)(3,2,0)(3,1,0)(1,1,1)  同上

**1 つの条項で族 α と SandwichU の両方が落ちる見込みがある。**

## 3. 族 β（A1, A2）— 余分な影の写しが出る

長さが**合わない**。`conv3(A<n>)` が、像の展開には無い写しを余分に出す。

    A1, m=2: |f(A)<2>| = 12、|f(A<3>)| = 17
             f(A)<2> = 接頭 7 本 + (3,2,0)(4,3,1)(5,0,0)(6,1,0)(7,2,1)
             f(A<3>) = 接頭 7 本 + (2,1,0)(3,2,1)(4,0,0)(5,1,0)(6,2,1)
                                 + (3,2,0)(4,3,1)(5,0,0)(6,1,0)(7,2,1)
             -> f(A)<2> は f(A<3>) から**最初の写しを 1 本抜いたもの**。
    A2, m=3: f(A<4>) には (4,1,0)(5,2,1) / (6,1,0)(7,2,1) という
             繰り返しの影の対が余分に入っている。

族 β は族 α とは**別の病**。逆像 B は A<n> ではなく別の標準形になる。
**先に族 α を落とすこと**（こちらは正解が完全にわかっている）。

## 4. 逆写像 d2b3 は m>=2 で全滅する

    A1  m=1 のみ当たる    A2  m=1,2 のみ    A3  m=1 のみ    A4  m=1 のみ
    （m=1..14 を全部試した）

つまり**散発的な取りこぼしではなく系統的な誤り**。だから
「大きい m なら当たる」ということは無い（次の項も参照）。

## 5. 要件は `ImgClosedT`（すべての m）ではなく `ImgCofinalT`（いくらでも大きい m）でよい

`ReindexT1_of_block` が `ImgClosedT3` から実際に使うのは **`m := n+1` ただ 1 つ**。
だから

    ImgCofinalT3: 任意の m0 に対し、ある m >= m0 と標準形 B があって
                  (conv3 A)<m> = conv3 B

で足りる。差を埋める補題（展開指数についての単調性）は
**`lean/Cofidx.lean` に証明済み（sorry 0, 終了コード 0）**、
`ReindexT1_of_cofinal` の証明本体は `lean/PATCH-imgcofinal.md` にある。

採点するときは「破れた／破れない」だけでなく
**A ごとに逆像を持つ m の集合**を出すこと。上の項 4 のとおり、
いまの 4 個は m>=2 が全滅なのでこの弱めでは救えない（＝ conv3 を直すしかない）。

# 追記 2（2026-08-28, 方針）

## 6. 根本は「写しをまたぐと状態が漏れる」こと

G2 の測定でいちばん効く数字はこれ:

    悪い部分の根 N[r] の出どころ:  sh0 42 / sh1 36 / body 10
    -> **78/88 で「conv3(A) の悪い部分は影の柱から始まる」**
    直す向き:  浅すぎ 71 / 深すぎ 9 / 行 0 がずれ 6 / 候補が非標準 2
    -> **一律に深くするのは誤り**（F4 の 7 個・F8 の 2 個は深すぎる）

`A<n>` は `A` の末尾を n 回写したものである。もし `conv3` が

    **写し同変**: conv3(G + C + C' + ...) の写し k 番目 =
                  写し k-1 番目を上昇分だけずらしたもの

を満たすなら、`(conv3 A)<m>` と `conv3(A<n>)` は自動的に一致する
（DBMS の展開がやっているのはまさに「ずらして写す」だけだから）。
**破れはすべて「写しの境目で状態が漏れている」ことの現れ**である。

漏れる状態は `conv3` が持ち回っている 5 つ:

    st['prev']  1 ビットの分岐状態     <- F1(31) F11(2) F13(1) がここ
    st['dmap']  もとの段 -> 像の段      <- F2(21) の (-1,-1,0) はここの疑い
    st['ST']    祖先スタック
    L / F       行 1 のユニットの表
    st['Mo'], off  行列ぜんぶ＋位置（後ろ向きの窓）

## 7. だから、枝ごとの逆算より先に「同変性を直に測れ」

条項を 1 本ずつ当てる前に、**どこで漏れているか**を測るほうが速い:

1. `A` と `n` を取り、`A<n>` を作る。`A<n>` の写しの境目の位置は既知
   （悪い部分の根 r と写しの長さ `len(A)-r` から出る）。
2. `conv3(A<n>)` を走らせながら、**各写しの頭で `st` を丸ごと記録**する。
3. 写し k の頭の `st` と、写し k-1 の頭の `st` を「上昇分だけずらしたもの」を
   比べる。**最初にずれた成分が犯人**である。
4. その成分がなぜずれたか（どの分岐が書き換えたか）を見て条項にする。

G2 が作った `tools/dbms/g2/provc.py`（柱ごとの出どころを記録する `conv3` の写し、
<=6 列 8387 個で `b2d3` と食い違い 0）がそのまま土台に使える。

## 8. `ImgCofinal` への弱めは、いまの 4 個は救わない（測った）

    逆写像 d2b3 が当たる m:  A1 {1} / A2 {1,2} / A3 {1} / A4 {1}   （m=1..14 を全部）
    探索（段 2）の救出:      <=6 列 173 対で **0 件**

系統的な誤りなので「大きい m なら当たる」ことは無い。
弱め自体は Lean に入れた（commit 7faa432、`ST_D3_conv3_of_parts` の仮定が
`ImgCofinalT3` になった）が、**conv3 を直す仕事は減らない**。
