# 拡張 Buchholz の標準形の整礎性 — 区別された集合による構文的証明（設計）

[← 戻る](README.md)

目標: 標準形の項の集合 OT の上で、辞書式順序 `<` が整礎であること。順序数への評価は使わない。

方法は Buchholz の「区別された集合（distinguished sets）」。
Arai の [Wellfoundedness proof with the maximal distinguished set](https://arxiv.org/abs/2211.08619)（2022）
と [Lectures on Ordinal Analysis](https://arxiv.org/abs/2304.00246) の 3 節の組み立てに倣い、拡張 Buchholz に合わせて作り直した。
拡張 Buchholz では主項どうしの比較が (添字, 引数) の辞書式なので、Arai の証明で一番重い部分
（Mahlo 次数、G_κ 集合、反射原理）はいらない。

## なぜ区別された集合か

Buchholz (1987) の方法（pss-proof）は、段 u ごとの集合 W_u を u の小さい方から再帰で作る。
拡張 Buchholz では添字 u が項なので、この再帰には添字の順序の整礎性が先に要り、循環する。
Arai 2022 の序論の言葉では、記法の中に記法自身の順序型と同じ数だけ正則順序数がある場合は、この過程を内部化する必要があり、
そこで区別された集合が出てくる。区別された集合は再帰を使わずに定義する（「自分の下では正しい W になっている集合」）。
その合併 W が最大の区別された集合になる。

## 記号

- 項 `T ::= 0 | ψ_ν(a) + c`（リスト形、和は左から非増加）。主項は ψ_ν(a)（c = 0）。
- `<` は (添字, 引数, 残り) の辞書式。OT は標準形（`Ytosk/lean/Ytosk/OT.lean`）。
- 項 α ≠ 0 の段 lev(α) := 先頭の主項の添字。lev(0) := 0。
- Ω_ν := ψ_ν(0)。ν + 1 := ν の末尾に 1 = ψ_0(0) を足したもの。
- α⁺ := Ω_{lev(α)+1}（α の上の最小の正則項）。
- α ≤ X :⇔ X のある元 δ で α ≤ δ。X < β :⇔ X の元はすべて β より小さい。X ∩ β := {δ ∈ X : δ < β}。
- W(Y) := Y の整礎部分（<↾Y について可到達な Y の元）。

## 定義

**C^α(X)**（X ∩ α を土台に、α より上の正則数に向かう崩壊で閉じたもの）: OT の部分集合で、次で閉じた最小のもの。

1. 0 ∈ C^α(X)。
2. δ ∈ X、δ < α なら δ ∈ C^α(X)（土台）。
3. x, y ∈ C^α(X) で x + y ∈ OT なら x + y ∈ C^α(X)（和）。
4. ν ∈ C^α(X) なら Ω_ν ∈ C^α(X)（基数は段によらず自由に作れる）。
5. ν, b ∈ C^α(X)、b ≠ 0、ν ≥ lev(α)、ψ_ν(b) ∈ OT なら ψ_ν(b) ∈ C^α(X)（行き先 Ω_{ν+1} が α より上の崩壊だけ）。

**区別された集合**: X ⊆ OT が区別されている（D[X]）:⇔ すべての α ∈ OT について、
α ≤ X ならば W(C^α(X)) ∩ α⁺ = X ∩ α⁺。

**W** := 区別されたすべての集合の合併。

**G(X)** := {α ∈ OT : α ∈ C^α(X) かつ C^α(X) ∩ α ⊆ X}。

**≺**: γ ≺ η :⇔ ある ν と b ≠ 0 で γ = ψ_ν(b)、η = Ω_{ν+1}（γ の行き先が η）。

## 順序についての準備（構文的な補題）

- `<` は T 上の狭義全順序。主項は ψ_ν(a) < ψ_μ(b) ⇔ ν < μ ∨ (ν = μ ∧ a < b)。
- 添字は項より小さい: ν < ψ_ν(a) + c。残りは項より小さい: c < ψ_ν(a) + c（和が非増加のとき）。
- α ≠ 0 なら α < Ω_μ ⇔ lev(α) < μ。α < β⁺ ⇔ lev(α) ≤ lev(β)。α < α⁺。
- x < y ならば x + 1 ≤ y。x + 1 < y + 1 ならば x < y。
- β⁺ < η⁺ ならば β⁺ ≤ η。
- 主項 p と項 γ で p < γ ならば p ≤ γ の先頭。
- α < δ < α + β（和が非増加）ならば δ = α + δ′、δ′ < β。

## 補題（番号は Arai の講義ノート 3 節との対応）

**補題 1（3.3）** X の元 γ がすべて γ ∈ C^γ(X) を満たすとする。
(1) α ≤ β ならば C^β(X) ⊆ C^α(X)。(2) lev(α) = lev(β) ならば C^α(X) = C^β(X)。

証明: 項の長さの帰納法で「β ≥ α、γ ∈ C^β(X) ならば γ ∈ C^α(X) ∪ (X ∩ β)」を示す。
土台の元 δ ∈ X ∩ β で δ ≥ α のものは、仮定 δ ∈ C^δ(X) と帰納法の仮定（β := δ）で C^α(X) に入る。
崩壊の条件 ν ≥ lev(β) ≥ lev(α) はそのまま通る。(2) は段が同じなら崩壊の条件も土台も（段の中では）変わらないことから。

**補題 2（3.6）** D[X]、α ∈ X ならば、すべての β で α ∈ C^β(X)。

**補題 3（3.8）** D[X]、D[Y]、α ≤ X、α ≤ Y ならば X ∩ α⁺ = Y ∩ α⁺。
証明: まず X ∩ α = Y ∩ α を、X と Y の整礎性で取った最小の食い違いが起きないことで示す
（最小の食い違い ε の下では X と Y が一致するので C^ε(X) = C^ε(Y)、両方の D から ε は両方に入る）。
C^α(X) は X ∩ α だけで決まるので、D[X]・D[Y] から結論が出る。

**補題 4（3.9）** D[W]。さらに W の元 α について W ∩ α ⊆ W(C^α(W)) なので、**W は整礎**。

**補題 5（3.11）** D[X] ならば X ⊆ G(X)。

**補題 6（3.18）** D[X]、α, β ∈ X、α + β ∈ OT ならば α + β ∈ X。
証明: C^α(X) の中で β についての帰納法で α + β が可到達であることを示し、α + β < α⁺ と D[X] を使う。

**補題 7（3.17）** D[X]、α ∈ X ならば α の先頭の主項と残りも X に入る。

**補題 8（3.15）** D[Y]、α ∈ G(Y)、X := W(C^α(Y)) ∩ α⁺ とする。次の条件 (14) が成り立てば、α ∈ X かつ D[X]。

  (14) すべての β で、Y ∩ α⁺ < β かつ β⁺ < α⁺ ならば W(C^β(Y)) ∩ β⁺ ⊆ Y。

証明は講義ノートの通り（X ∩ α = Y ∩ α = C^α(Y) ∩ α、段が α と同じ元 γ ∈ X について γ ∈ C^γ(X)、
β⁺ = α⁺ と β⁺ < α⁺ に分けて D[X] を確かめる）。

**補題 9** 0 ∈ W。補題 8 を Y = ∅、α = 0 に使う（(14) は β⁺ < Ω_1 となる β がないので空虚）。

**補題 10（鍵、3.21 / 3.26 の拡張 Buchholz 版）** η ∈ G(W) で、γ ≺ η なる γ ∈ G(W) がすべて W に入るならば、η ∈ W。

証明: 補題 8（Y = W）の条件 (14) を示す。W ∩ η⁺ < β、β⁺ < η⁺ とし、γ ∈ W(C^β(W)) ∩ β⁺ について
γ ∈ W を、C^β(W) の中の可到達性の帰納法で示す（MIH: C^β(W) ∩ γ ⊆ W）。

- γ ≤ δ ∈ W ∩ η⁺ となる δ があれば、δ < β、C^β(W) ⊆ C^δ(W)、D[W] から γ ∈ W。以下 W ∩ η⁺ < γ（特に γ ∉ W）。
- γ の作り方で場合分け。土台なら γ ∈ W で矛盾。和 x + y なら x, y < γ なので MIH で W に入り、補題 6。
- γ = Ω_ν（規則 4）: ν < γ なので MIH で ν ∈ W。ν ∈ C^η(W)（補題 2）なので Ω_ν ∈ C^η(W)。
  γ < β⁺ ≤ η と η ∈ G(W) から γ ∈ W。
- γ = ψ_ν(a)、a ≠ 0（規則 5）: ν ≥ lev(β) と γ < β⁺ から ν = lev(β)、γ の行き先は Ω_{ν+1} = β⁺。
  段が同じなので C^γ(W) = C^β(W)、MIH と合わせて γ ∈ G(W)。
  - β⁺ = η なら γ ≺ η なので仮定から γ ∈ W。
  - β⁺ < η なら、ν ∈ W（MIH）から Ω_{ν+1} ∈ C^η(W) ∩ η ⊆ W。すると W ∩ η⁺ < γ より Ω_{ν+1} < γ = ψ_ν(a) となり矛盾。

**補題 11** G(W) ⊆ W。Ω_{μ+1} の形でない η では補題 10 の仮定が空虚。Ω_{μ+1} では、
それに ≺ な γ = ψ_μ(b)（b ≠ 0）は Ω の形でないので先の場合で W に入る。

**補題 12（Ω での閉包）** σ ∈ W ならば Ω_σ ∈ W。σ ∈ W についての帰納法。
Ω_σ ∈ C^{Ω_σ}(W) で、C^{Ω_σ}(W) ∩ Ω_σ の元は（項の長さの帰納法で）土台・和・Ω_μ（μ < σ、帰納法の仮定）なので W に入る。
よって Ω_σ ∈ G(W)、補題 11。

**補題 13（ψ での閉包、3.36 の拡張 Buchholz 版）** σ, a ∈ W、ψ_σ(a) ∈ OT ならば ψ_σ(a) ∈ W。
a ∈ W についての帰納法（MIH(a): b ∈ W ∩ a と τ ∈ W で ψ_τ(b) ∈ OT ならば ψ_τ(b) ∈ W）。a = 0 は補題 12。
α₁ := ψ_σ(a)、a ≠ 0 とし、α₁ ∈ G(W) を示せば補題 11 で終わる。α₁ ∈ C^{α₁}(W) は補題 2 から。
C^{α₁}(W) ∩ α₁ ⊆ W を項の長さの帰納法で示す。β₁ ∈ C^{α₁}(W) ∩ α₁ が主項のとき:

- 土台なら W の元。Ω_μ なら μ < β₁ で、帰納法の仮定と MIH（b = 0 < a）。
- ψ_π(b)、b ≠ 0（規則 5）なら π ≥ σ と β₁ < α₁ から π = σ、b < a。
  「C^{α₁}(W) の元 b′ で、段 σ 以上の成分がすべて a より小さいものは W に入る」を b′ の長さの帰納法で示す
  （α₁ 未満の部分は外側の帰納法の仮定、α₁ 以上の部分は和・Ω・崩壊のどれかで、崩壊 ψ_τ(c) の c は段 σ 以上の成分なので c < a、MIH）。
  標準形の条件から b の段 σ 以上の成分は b より小さく、したがって a より小さいので b ∈ W、MIH で β₁ ∈ W。

**定理** OT ⊆ W。項の構造についての帰納法（ψ_ν(a) + c は補題 13 と補題 6）。補題 4 から、OT 上の `<` は整礎。

## 標準形の条件が効くところ

標準形の条件（段 σ 以上の成分が引数より小さい）は、補題 13 の「内側の崩壊の引数 c は a より小さい」でだけ使う。
これがないと、たとえば ψ_0(ψ_0(Ω_1)) を許して ψ_0(Ω_1) > ψ_0(ψ_0(Ω_1)) > … の無限降下列ができる。
