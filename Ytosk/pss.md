# 2 行の断片での降下（正規形を仮定）

[← 戻る](desc.md)

行 2 がすべて 0 の行列（ペア数列、PSS）について、eval(M[n]) < eval(M) を示す。
途中の値が標準形であること（正規形定理）は仮定 (NF) に置く。
項の補題は `lean/Ytosk/SP.lean`（`frame_same`・`frame_prefix`・`spArg_frame_diff`・`spArg_eq_app`）。

## 設定

M = (a_0, b_0) … (a_x, b_x)（行 2 は 0）、標準形。P_0, P_1 は行 0・行 1 の親。

標準形の事実（実測で全件、2026-10-01、`tools` の乱択で約 33 万列）:

- (F1) b_i > 0 なら b_i = b_{P_1(i)} + 1。
- (F2) b_i ≤ b_{P_0(i)} + 1。

評価器（行 2 が 0 なので上げも上に乗る子もない）:

- v(i) = b_i（自然数 b_i を 1 + … + 1 と読む。F1 から）。
- ch(i) = 行 0 の子（列の順）。o(i) = ψ_{b_i}(Σ_{c ∈ ch(i)} o(c))。
- 正規化した値 o′(i) = sp(b_i, 0, S_i)、S_i = Σ_{c ∈ ch(i)} o′(c)。o′(i) = ψ_{b_i}(σ_i)、σ_i = spArg(b_i, 0, S_i)。
- eval(M) = Σ_{根} o′（根 = (0,0) の列）。

仮定 (NF): M と M[n] のすべての列で o′(i) は標準形、S_i は降順（加数が増えない）。

## 展開の形

x を最後の列とし、x ≠ (0,0)、n ≥ 1 とする（x = (0,0) なら M[n] は最後の加数 1 を落とすだけ。n = 0 は M[0] = M の先頭部分で、
[1] の繰り返しで得られるので n = 1 に帰着）。

t = 1（b_x > 0）か t = 0（b_x = 0）、r = P_t(x)、B = 列 r … x−1、q = P_0(x)、d = a_x − a_r（t = 1）か 0（t = 0）。

- (E1) M[n] = M の先頭 x 列 ++ C_1 ++ … ++ C_{n−1}、C_k は B の行 0 に k·d を足したもの（B の列はすべて r の行 0 の子孫なので全部が上昇する）。
- (E2) 親: x より前の列の親は M と同じ。C_k の中では、r 以外の列 c のコピーの P_0 は P_0(c) の同じコピー。
  根のコピー r⁽ᵏ⁾ の P_0 は、t = 1 なら q⁽ᵏ⁻¹⁾（q⁽⁰⁾ = q）、t = 0 なら P_0(r)。行 1 は上昇しないので P_1 も同じ形。
- (E3) 背骨 S: r から q への行 0 の道 r = s_0, s_1, …, s_m = q（t = 0 なら q = r）。背骨の列はそれぞれ親の最後の子。

## コピーの値

- (V1) 背骨でない B の列 c とそのコピー: 部分木が同じなので o′ は M での値に等しい（実測 6,423 件すべて）。
- (V2) 背骨の列: s_i⁽ᵏ⁾ の子は P_{s_i}（背骨でない子のコピー、値は同じ）に続いて s_{i+1}⁽ᵏ⁾。
  q⁽ᵏ⁾ の子は P_q に続いて r⁽ᵏ⁺¹⁾（k < n−1）か、続きなし（k = n−1）。

値 X（または「なし」⊥）に対し F_m(X) = sp(b_q, 0, P_q ++ [X])、F_i(X) = sp(b_{s_i}, 0, P_{s_i} ++ [F_{i+1}(X)]) とおくと、

- M で o′(r) = F_0(Ω_{b_x})（x は子のない列で o′(x) = ψ_{b_x}(0) = Ω_{b_x}）。
- M[n] で o′(r⁽ⁿ⁻¹⁾) = F_0(⊥)、o′(r⁽ᵏ⁾) = F_0(o′(r⁽ᵏ⁺¹⁾))、コピー 0 の r は F_0(o′(r⁽¹⁾))。

## t = 1 の降下

**(D1) q での段（底のすぐ上）**: Y = o′(r⁽¹⁾) = ψ_{b_r}(y_1)、b_r < b_x とし、F_m(Y) < F_m(Ω_{b_x})、F_m(⊥) < F_m(Ω_{b_x})。

- ⊥ の場合は打ち切りの段（`spArg_frame_prefix`、大きい側の残りは空）。
- Y の場合は添字が違う段（`spArg_frame_diff`）。小さい側の残りは空。条件 (ii) は Y が書き換えうるときだけ要る。
  - q ≠ r なら b_q ≥ b_x > b_r（q は r と x の間の x の祖先で、P_1(x) = r より行 1 が b_x 以上）。Y の添字 b_r < b_q なので書き換えない。
  - q = r なら下の (C)。

**(C) コピーの根の鎖（q = r のとき）**: b = spArg(b_r, 0, P_r)、B = b の Ω_{b_r+1} 以上の部分とする。
y_k を o′(r⁽ᵏ⁾) の引数とすると、y_{n−1} = b、k ≤ n−2 では y_k の Ω_{b_r+1} 以上の部分は B で、低い部分は 0 でない。

- y_{n−2} = step(b, ψ_{b_r}(b))。b < b なので書き換えず b + ψ_{b_r}(b)。b の低い加数は ψ_{b_r}(b) より小さい（ψ_{b_r}(b) が標準形）ので落ち、
  y_{n−2} = B ++ ψ_{b_r}(b)。
- k ≤ n−3: y_k = step(b, ψ_{b_r}(y_{k+1}))。b < y_{k+1}（b = B ++ 低い部分、低い部分 < ψ_{b_r}(b) ≤ y_{k+1} の低い部分の先頭）なので書き換え、
  y_k = H(b_r, y_{k+1}) = B ++ ψ_{b_r}(y_{k+1})。

したがって Y が書き換えるときの状態は H(b_r, y_1) = B ++ ψ_{b_r}(y_1) で、b_x = b_r + 1（F1）より
W0 = b + Ω_{b_x} = B ++ Ω_{b_r+1}。ψ_{b_r}(y_1) < Ω_{b_r+1} なので SB(H, W0)。

**(D2) 背骨を上る**: X < X′ が同じ添字 b_{s_{i+1}} を持てば F_i(X) < F_i(X′)。添字が同じ段（`spArg_frame_same`）で、
両側とも残りは空（背骨の列は親の最後の子）。

**(D3) r より上**: r の祖先 h でも、道の子は最後の子で添字は両側で同じ（列が同じ）。`spArg_frame_same`、残りは空。
コピーはすべて q の子孫なので、h の子は増えない。

**根**: x を含む根の値が下がり、それより前の根は変わらず、後ろに根はない。add の右についての狭義単調性（`add_lt_add_left`）。

## t = 0 の降下

q = r、x は r の最後の子で o′(x) = ψ_0(0) = 1。M[n] で r⁽ᵏ⁾（k = 1 … n−1）はどれも r の兄弟で、部分木は x を除いた r の部分木と同じ。
c_u = o′_{M[n]}(r) = sp(b_r, 0, P_r)、c_w = o′_M(r) = sp(b_r, 0, P_r ++ [1])。

- r での段: 打ち切りの段（P_r と P_r ++ [1]）。σ_u < σ_w。
- g = P_0(r) での段: 小さい側の子の並び P_g ++ [c_u, c_u, …, c_u]（n 個）、大きい側 P_g ++ [c_w]。添字が同じ段で、
  小さい側の残り [c_u]ⁿ⁻¹ は書き換えない（`spArg_eq_app`: 残りの各加数 ψ_{b_r}(σ_u) について、step のあとの状態は σ_u 以上。
  書き換えたなら H ≥ σ_u（`le_H`）、書き換えないなら b ≥ σ_u か b_r < b_g）。
- r が根なら（a_r = 0）、根の和で同じ比較（add のみ）。
- g より上は (D3) と同じ。

## Lean にするときの部品

1. 2 行の行列で評価器の等式（v = b、o′ の再帰）と、eval が値を持つこと。
2. (E1)(E2): `expand` の形とコピーの親。trio 本体の `oper_bad_unfold`・`gexp_nextrel0_mir`・`gexp_nextrel0_root` に当たる。
3. (V1)(V2): コピーの値。
4. (C): 鎖の補題（項の側で書ける: b と P から y_k を作る漸化式についての補題）。
5. 上の段の積み上げ。
