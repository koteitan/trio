# 段 1（翻訳が展開で下がる）— 作業記録

[← 戻る](README.md)

目標（Lean の `Ytosk.Desc`、`lean/Ytosk/BMS.lean`）: SRO から展開でたどり着く行列 M（SRO 以外）について、

- eval(M) は値を持ち（v と o が循環しない）、標準形（isOT）である。
- すべての n で eval(M[n]) < eval(M)。

これと段 2（`wf_OT`）から、段 3 `terminates_of_desc` により、SRO から始めた展開は必ず止まる。
Ytosk 氏のブログにも「この解析に証明はない」とある部分で、ここが本体。

## 数値での確認

- `tools/probe_desc.py`: SRO からの乱択の展開（n ≤ 3、30 列まで）で、行列 3221 個・展開 3945 組。
  下がらない組 0、値のない行列 0（SRO を除く）、標準形でない値 0。
- `tools/ytosk_eval.py`: 翻訳写像の Python 版（Lean 版とシートの 4767 行で一致）。列ごとの o・v・親・上げ役を出せる。

## 値の依存の形

翻訳の値は列ごとの o(n) = ψ_{v(n)}(数える子の o の和) と添字 v(n) から組み立てられ、依存は次の通り。

- o(n) ← v(n) と、行 0 の子の o。
- v(n)（行 2 が 0）← v(P_1(n)) と、上げ役 U(n) の v。U(n) は n+1 か、行 0 の祖先。
- v(n)（行 2 が 1）← v(P_1(n)) と、「上に乗る子」(M_n,0+1, M_n,1, 1) の子（孫）の o。

後ろの列への依存は「部分木」と「U(n) = n+1」の 2 つ。U(n) = n+1 の n+1 は部分木の外（後ろの兄弟など）のことがあるので、
依存は木ではなく後ろへ伸びる辺を持つ DAG になる。

実測（乱択の展開の組で、良い部分の列 g < r の値が M と M[n] で変わるか）:
悪い根 r の行 0 の祖先は（当然）変わるが、祖先でない列も変わる。例えば
(0,0,0)(1,1,1)(2,1,1)(3,1,0)(1,1,1)… の列 3 = (3,1,0) は U(3) = 4（後ろの兄弟 (1,1,1)）なので、
列 4 の部分木の変化が列 3、さらにその祖先の列 1, 2 に伝わる。
したがって段 1 は「変わる場所の局所的な減少 + 木に沿った単調性」だけでは閉じず、上げの辺に沿った単調性も要る。

## 列ごとの単調性（実測）

M と M[n] に共通な列 i < x（良い部分と、悪い部分の 0 番目のコピー）で、標準形に直した値を比べた
（展開の組 8853 個、列のべ 116,271 個）:

| o | v | 列数 |
|---|---|---|
| = | = | 33,918 |
| < | = | 59,441 |
| < | < | 22,912 |
| > または v > | | **0** |

**値が大きくなる列はない。** これから証明の形は次の 2 段になる見込み。

- **(I) 列ごとの単調性**: 共通な列では o_{M[n]}(i) ≤ o_M(i)、v_{M[n]}(i) ≤ v_M(i)。依存の DAG に沿った帰納法。
- **(II) 根での真の減少**: 最後の根で真に下がる。

難所:
- 項の側で、標準形化 sf・ω 冪・和の単調性を構文的に示す（例: sf(A) ≤ sf(A′) ⇒ sf(ψ_v(A)) ≤ sf(ψ_v(A′))）。
- 上げの `last(v(U n))` は一般の項では単調でない（X = ω²、X′ = ω²+1 で last が逆転）。標準形の行列の上でだけ単調に
  振る舞う理由を、行列の形から示す必要がある。

## 上げの式の読み替え

U(n) が定義されるとき、U(n) は行 2 が 1 で P_1(U n) = P_1(n)。したがって v(U n) = v(P_1 n) + ω^{p(U n)}、
last(v(U n)) = ω^{p(U n)}（ω 冪はいつも主項 1 つ）。上げの式は **v(n) = v(P_1 n) + ω^{p(U n)}** と読め、p について単調。
（一般の項では last は単調でないが、ここでは問題にならない。v(U n) 自体は和になることがある: 28,800 件中 5,436 件。）

## 局所的な真の減少（実測）

x の親 q = P_0(x) の値 o(q) は、x の役割によらず必ず真に下がる（展開の組 15,516 個）。

| t | x の役割 | v(q) | o(q) | 件数 |
|---|---|---|---|---|
| 0 | 普通 | = / < | **<** | 1424 |
| 1 | 普通 | = / < | **<** | 8821 |
| 2 | 上に乗る子 (q₀+1, q₁, 1) | < | **<** | 1814 |
| 2 | 上げ役（上げた列の v も <） | = | **<** | 702 |
| 2 | 普通 | = / < | **<** | 2755 |

t = 1 では最初のコピーの根 r⁽¹⁾（x の位置に入る、親は q）で v(r⁽¹⁾) < v(x)（2672 件すべて）。
t = 2 ではそうとは限らず（= が 1226、> が 57）、上に乗る子なら v(q) の p から 1 が消えることで下がる。
t = 0 ではコピーは r の兄弟として P_0(r) に並ぶので、P_0(r) では ψ_v(S)·n < ψ_v(S+1) の形の比較になる。

**証明の骨格（見込み）**
- (LOC) o_{M[n]}(P_0(x)) < o_M(P_0(x))（t = 0 は P_0(r) での n 個の比較まで含める）。
- (MONO) 共通な列の値は増えない。
- (PROP) 真の減少は行 0 の祖先へ伝わり、最後の根で全体が下がる。

## 項の側: 各段で標準形に直す eval′ と、正規化 sp の正体

- **eval′**（`tools/ytosk_eval2.py`）: o と v を作るたびに sf をかける版。Ytosk 氏の eval と 11,385 行列中 11,383 で一致（シートは全行一致）。
  eval′ でも展開で値が下がり（17,524 組）、共通な列の値は増えない。途中の値はすべて標準形（10,084 個）。以後の対象は eval′。
- 実測（途中の値の上で）: 標準形の和・ω 冪は標準形、sf は標準形の上で恒等、ψ の正規化 psiN(v, S) = sf(ψ_v(S)) は v と S の両方について単調
  （乱択 40,000 組）。和の性質は Lean で証明済み（`Arith.lean`: `isOT_add`、左右の単調性）。
- **sp は「S 以上で許される最小の引数」ではない。** S が許されないとき sp は S より大きい許される β を返すが、
  S ≤ β′ < β なる許される β′ が多数ある。例えば sp は ψ_0(ψ_0(Ω_2)) を ψ_0(Ω_2) に直すが、Buchholz の意味では
  ψ_0(ψ_0(Ω_2)) = ψ_0(Ω_1)（C_0(BH) ∩ Ω_1 = ε_0 なので）。ブログの SF の規則には共終数の条件があり、JS の sp とは形が違う。
  それでも翻訳の値はシートのラベルと合うので、途中の項（NSE）は行列の文脈の中間表現で、Buchholz の項として読むものではない。
  したがって証明では sp の実装そのものについて「標準形を返す」「単調」を示す必要がある。
- **sp は任意の標準形の入力では正しくない。** 途中の値の部分項から乱択で作った入力 60,000 組のうち 4 組で、sp は標準形でない値を返し、
  単調性も崩れる。例: a = 0、S = ψ_1(Ω_μ)（μ は可算で、Ω_{Ω_1} のような大きな成分を含む）に対し sp は ψ_0(Ω_μ) を返すが、
  添字 μ の成分が Ω_μ より大きいので標準形でない。sp は引数を y の高い部分に置き換えたあと、それをもう一度正規化しない。
  翻訳の中で実際に出る入力（10,084 個の値）では起きないので、sp の正しさは行列から来る入力の形に依存する。
  項の側の補題には、行列の側から来る条件を仮定として持たせる必要がある。
- **行列の文脈での sp の閉じた形**（7,030 件すべて）: 書き換えはちょうど 1 回で、置き換え後の引数はその後ずっと許される。
  S = c₁ + c₂ + …、c₁ = ψ_s(y) とすると、S > Ω_a かつ y ≠ 0 なら sp は ψ_a(H(y) + c₂ + …) を返し
  （H(y) = y の Ω_{s+1} 以上の部分、y に低い部分があればそれに ψ_s(y) を足したもの）、そうでなければ ψ_a(S)。
  証明に要る行列の側の不変条件は 2 つ: (i) 書き換えは先頭の加数の 1 回だけ（以後の加数 ψ_{s_j}(y_j) では b ≥ y_j）、
  (ii) H(y) + c₂ + … は a について許される。
