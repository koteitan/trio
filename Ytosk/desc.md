# 段 1（翻訳が展開で下がる）— 作業記録

[← 戻る](README.md)

目標（Lean の `Ytosk.Desc`、`lean/Ytosk/BMS.lean`）: SRO から展開でたどり着く行列 M（SRO 以外）について、

- eval(M) は値を持ち（v と o が循環しない）、標準形（isOT）である。
- すべての n で eval(M[n]) < eval(M)。

これと段 2（`wf_OT`）から、段 3 `terminates_of_desc` により、SRO から始めた展開は必ず止まる。
Ytosk 氏のブログにも「この解析に証明はない」とある部分で、ここが本体。

## 数値での確認

- `tools/probe_desc.py`: SRO からの乱択の展開（n ≤ 3、30 列まで）で、行列 3221 個・展開 3945 組。
  下がらない組 0、値のない行列 0（SRO を除く）、標準形でない値 0。
- `tools/ytosk_eval.py`: 翻訳写像の Python 版（Lean 版とシートの 4767 行で一致）。列ごとの o・v・親・上げ役を出せる。

## 値の依存の形

翻訳の値は列ごとの o(n) = ψ_{v(n)}(数える子の o の和) と添字 v(n) から組み立てられ、依存は次の通り。

- o(n) ← v(n) と、行 0 の子の o。
- v(n)（行 2 が 0）← v(P_1(n)) と、上げ役 U(n) の v。U(n) は n+1 か、行 0 の祖先。
- v(n)（行 2 が 1）← v(P_1(n)) と、「上に乗る子」(M_n,0+1, M_n,1, 1) の子（孫）の o。

後ろの列への依存は「部分木」と「U(n) = n+1」の 2 つ。U(n) = n+1 の n+1 は部分木の外（後ろの兄弟など）のことがあるので、
依存は木ではなく後ろへ伸びる辺を持つ DAG になる。

実測（乱択の展開の組で、良い部分の列 g < r の値が M と M[n] で変わるか）:
悪い根 r の行 0 の祖先は（当然）変わるが、祖先でない列も変わる。例えば
(0,0,0)(1,1,1)(2,1,1)(3,1,0)(1,1,1)… の列 3 = (3,1,0) は U(3) = 4（後ろの兄弟 (1,1,1)）なので、
列 4 の部分木の変化が列 3、さらにその祖先の列 1, 2 に伝わる。
したがって段 1 は「変わる場所の局所的な減少 + 木に沿った単調性」だけでは閉じず、上げの辺に沿った単調性も要る。

## 列ごとの単調性（実測）

M と M[n] に共通な列 i < x（良い部分と、悪い部分の 0 番目のコピー）で、標準形に直した値を比べた
（展開の組 8853 個、列のべ 116,271 個）:

| o | v | 列数 |
|---|---|---|
| = | = | 33,918 |
| < | = | 59,441 |
| < | < | 22,912 |
| > または v > | | **0** |

**値が大きくなる列はない。** これから証明の形は次の 2 段になる見込み。

- **(I) 列ごとの単調性**: 共通な列では o_{M[n]}(i) ≤ o_M(i)、v_{M[n]}(i) ≤ v_M(i)。依存の DAG に沿った帰納法。
- **(II) 根での真の減少**: 最後の根で真に下がる。

難所:
- 項の側で、標準形化 sf・ω 冪・和の単調性を構文的に示す（例: sf(A) ≤ sf(A′) ⇒ sf(ψ_v(A)) ≤ sf(ψ_v(A′))）。
- 上げの `last(v(U n))` は一般の項では単調でない（X = ω²、X′ = ω²+1 で last が逆転）。標準形の行列の上でだけ単調に
  振る舞う理由を、行列の形から示す必要がある。

## 上げの式の読み替え

U(n) が定義されるとき、U(n) は行 2 が 1 で P_1(U n) = P_1(n)。したがって v(U n) = v(P_1 n) + ω^{p(U n)}、
last(v(U n)) = ω^{p(U n)}（ω 冪はいつも主項 1 つ）。上げの式は **v(n) = v(P_1 n) + ω^{p(U n)}** と読め、p について単調。
（一般の項では last は単調でないが、ここでは問題にならない。v(U n) 自体は和になることがある: 28,800 件中 5,436 件。）

## 局所的な真の減少（実測）

x の親 q = P_0(x) の値 o(q) は、x の役割によらず必ず真に下がる（展開の組 15,516 個）。

| t | x の役割 | v(q) | o(q) | 件数 |
|---|---|---|---|---|
| 0 | 普通 | = / < | **<** | 1424 |
| 1 | 普通 | = / < | **<** | 8821 |
| 2 | 上に乗る子 (q₀+1, q₁, 1) | < | **<** | 1814 |
| 2 | 上げ役（上げた列の v も <） | = | **<** | 702 |
| 2 | 普通 | = / < | **<** | 2755 |

t = 1 では最初のコピーの根 r⁽¹⁾（x の位置に入る、親は q）で v(r⁽¹⁾) < v(x)（2672 件すべて）。
t = 2 ではそうとは限らず（= が 1226、> が 57）、上に乗る子なら v(q) の p から 1 が消えることで下がる。
t = 0 ではコピーは r の兄弟として P_0(r) に並ぶので、P_0(r) では ψ_v(S)·n < ψ_v(S+1) の形の比較になる。

**証明の骨格（見込み）**
- (LOC) o_{M[n]}(P_0(x)) < o_M(P_0(x))（t = 0 は P_0(r) での n 個の比較まで含める）。
- (MONO) 共通な列の値は増えない。
- (PROP) 真の減少は行 0 の祖先へ伝わり、最後の根で全体が下がる。

## 項の側: 各段で標準形に直す eval′ と、正規化 sp の正体

- **eval′**（`tools/ytosk_eval2.py`）: o と v を作るたびに sf をかける版。Ytosk 氏の eval と 11,385 行列中 11,383 で一致（シートは全行一致）。
  eval′ でも展開で値が下がり（17,524 組）、共通な列の値は増えない。途中の値はすべて標準形（10,084 個）。以後の対象は eval′。
- 実測（途中の値の上で）: 標準形の和・ω 冪は標準形、sf は標準形の上で恒等、ψ の正規化 psiN(v, S) = sf(ψ_v(S)) は v と S の両方について単調
  （乱択 40,000 組）。和の性質は Lean で証明済み（`Arith.lean`: `isOT_add`、左右の単調性）。
- **sp は「S 以上で許される最小の引数」ではない。** S が許されないとき sp は S より大きい許される β を返すが、
  S ≤ β′ < β なる許される β′ が多数ある。例えば sp は ψ_0(ψ_0(Ω_2)) を ψ_0(Ω_2) に直すが、Buchholz の意味では
  ψ_0(ψ_0(Ω_2)) = ψ_0(Ω_1)（C_0(BH) ∩ Ω_1 = ε_0 なので）。ブログの SF の規則には共終数の条件があり、JS の sp とは形が違う。
  それでも翻訳の値はシートのラベルと合うので、途中の項（NSE）は行列の文脈の中間表現で、Buchholz の項として読むものではない。
  したがって証明では sp の実装そのものについて「標準形を返す」「単調」を示す必要がある。
- **sp は任意の標準形の入力では正しくない。** 途中の値の部分項から乱択で作った入力 60,000 組のうち 4 組で、sp は標準形でない値を返し、
  単調性も崩れる。例: a = 0、S = ψ_1(Ω_μ)（μ は可算で、Ω_{Ω_1} のような大きな成分を含む）に対し sp は ψ_0(Ω_μ) を返すが、
  添字 μ の成分が Ω_μ より大きいので標準形でない。sp は引数を y の高い部分に置き換えたあと、それをもう一度正規化しない。
  翻訳の中で実際に出る入力（10,084 個の値）では起きないので、sp の正しさは行列から来る入力の形に依存する。
  項の側の補題には、行列の側から来る条件を仮定として持たせる必要がある。
- **行列の文脈での sp の形**（7,030 件すべて）: 書き換えはちょうど 1 回で、置き換え後の引数はその後ずっと許される。
  書き換えが起きるのは「それまでの和 b を引数 y が超える最初の加数 c_k = ψ_s(y)」（S > Ω_a の範囲で）。
  位置は先頭 6,160 件、2 番目 1,203 件、3・4 番目が各 1 件。そのとき sp は ψ_a(H(y) + c_{k+1} + …) を返す
  （H(y) = y の Ω_{s+1} 以上の部分、y に低い部分があればそれに ψ_s(y) を足したもの。c_1 … c_{k-1} は捨てられる）。
  証明に要る行列の側の不変条件は 2 つ: (i) 書き換えは 1 回だけ（以後の加数 ψ_{s_j}(y_j) では b ≥ y_j）、
  (ii) H(y) + c_{k+1} + … は a について許される。

## t = 1 の局所的な減少の構造（実測 1018 件すべて）

- x は最後の列で行 2 が 0 なので v(x) = v(r) + 1（r = P_1(x)）。o(x) = Ω_{v(r)+1}。
- 最初のコピーの根 r⁽¹⁾ は行 0 だけ x と同じで、行 1・2 は r と同じ。P_1(r⁽¹⁾) = P_1(r)。
- v(r⁽¹⁾) ≤ v(r)（= 910、< 108）。

したがって o(r⁽¹⁾) < Ω_{v(r⁽¹⁾)+1} ≤ Ω_{v(r)+1} = o(x)。t = 1 の (LOC) は「コピーの根の添字 ≤ 元の根の添字」に帰着する。
t = 1 ではコピーの行 1・2 は元と同じ（上昇は行 0 だけ）なので、コピーの中の P_1・上げの構造は B と同じ形で、
値の違いは「x の代わりにさらに深いコピーが入る」ことだけ。自己相似な帰納法に乗る見込み。
t = 2 では行 1 も上昇するのでコピーの添字は上がり、別の仕組み（上に乗る子の消滅、上げ）で下がる。

## t = 2 の局所的な減少の構造（実測、n ≥ 2 の 1337 件すべて）

x は最後の列で行 2 が 1、子がないので p(x) = 1、v(x) = v(m) + ω（m = P_1(x)）。
最初のコピーの根 r⁽¹⁾ = (x₀, x₁, 0)（行 2 だけ x と違う）で、P_1(r⁽¹⁾) = m。

| x の役割 | r⁽¹⁾ の上げ U(r⁽¹⁾) | v(r⁽¹⁾) と v(x) | 下がる仕組み | 件数 |
|---|---|---|---|---|
| 普通 | なし | < （v(m)+1 < v(m)+ω） | q の子 x が小さい r⁽¹⁾ に置き換わる | 230 |
| 上げ役 | なし | < | 同上（上げられた列の v も下がる） | 288 |
| 上に乗る子 | あり | = | p(q) から x の項 ω^0 = 1 が消え、v(q) が真に下がる。o(r⁽¹⁾) は o(x) より大きいが、o(q) = ψ_{v(q)}(…) は引数によらず下がる | 819 |

上に乗る子の場合の v(q) の減少: p(q) = 1 + Σ_{上に乗る子 j} ω^{q(j)} で x は最後の上に乗る子、q(x) = 0。
M[n] では x が消え（r⁽¹⁾ は行 2 が 0 なので上に乗る子ではない）、残りの項は (MONO) で増えないので p(q) は真に下がる。

## 真の減少は祖先へ伝わる（実測）

x の親 q（t = 0 では P_0(r)）から根までの全祖先で o が真に下がる（20,686 組すべて）。
ψ の正規化は引数について弱単調でしかないが、行列の文脈では真の減少が消えない。見込みの理由: 変わる部分木は各段で
「最後の子」の部分木（x が最後の列なので）で、sp の書き換えが最後の加数で起きても H(y) は y について狭義単調。
ただし最後の子の値の添字が下がる場合（ψ_s(y) → ψ_{s′}(y)、s′ < s）は cut の閾値が下がるので、別に確かめる必要がある。

## 正規化する前の値 R で分ける（実測）

Lean の `ord`（`Eval.lean`）は sf をかける前の値を返し、eval はその和に最後に sf をかけるだけ。
この正規化する前の値を R(M) と書く（R(M) = Σ_{行 0 が 0 の列 i} ord(i)）。

SRO からの乱択の展開（40 列まで）で測った結果（`tools/probe_raw.py`）:

| 性質 | 件数 | 反例 |
|---|---|---|
| R の中の和はすべて降順（add と連結 app が一致） | 17,950 行列 | 0 |
| sf(R(M)) = eval(M) | 30,277 行列 | 0 |
| R は単射 | 30,277 行列 | 0 |
| sf は R の像の上で狭義単調（R(M) < R(M′) ⇒ eval(M) < eval(M′)） | 30,277 値 | 0 |
| 展開で R が下がる: R(M[n]) < R(M) | 35,402 組 | 0 |
| 共通な列 i < x で正規化前の o・v が増えない | 527,442 列 | 0 |

したがって段 1 は次の 2 つに分かれる。

- **(1a) R の減少**: R(M[n]) < R(M)。正規化がないので、o(n) = ψ_{v(n)}(子の o の降順の和) の辞書式の比較だけ。
  共通な列の子の並びは同じ長さなので、各子の o が増えなければ和も増えない（辞書式の比較は各成分の比較）。
  lean-yapss（2 行、https://github.com/koteitan/yet-another-pss-proof ）の第 3 章と同じ形の構文的な議論に乗る見込み。
- **(1b) sf の単調性**: 像の上で sf が狭義単調で、値が標準形。正規化 sp は任意の入力では単調でない（上の節）ので、
  像の形（行列から来る条件）を仮定に持つ項の補題になる。

v は add で作る（v の中まで連結にすると sf(R) ≠ eval が 20,919 件、単調性の反例 682 件）。

## (1b) の形: 違いの道に沿って 1 段ずつ持ち上げる（実測）

R(M[n]) と R(M) を根から辞書式に比べ、最初に違う位置までの道をたどる（和では共通の先頭の加数を飛ばし、
違う加数 ψ_a(b) と ψ_a′(b′) で a ≠ a′ なら添字へ、a = a′ なら引数へ降りる）。

- 最初の違いは必ず「小さい側の和が大きい側の和の先頭部分」（打ち切り）。9,478 組すべて。85% は道の途中で添字に入る。
- 道の上のすべての段で sf をかけた値も真に小さい（9,478 組すべて）。

したがって (1b) は底の打ち切りから 1 段ずつ持ち上げる形になる。段は 3 種類:

| 段 | 必要なこと | 状況 |
|---|---|---|
| 添字 | sf(ψ_a(b)) の添字は sf(a) | 自動 |
| 和 | 共通の先頭 P のあとの加数が真に小さければ、和の sf も真に小さい | add の性質 |
| 引数 | sp(a, 0, S) が S について真に単調 | 文脈が要る |

引数の段の sp の書き換え位置（S_u < S_w、最初の違いの加数の位置 j）の内訳（3 行、約 9 万段）:
両方 j で書き換え 46,085、両方書き換えなし 36,735、片方だけ j で書き換え 5,604、j より前で両方 739 など。
2 行の断片（行 2 がすべて 0）では「両方 j で書き換えて添字が違う」場合は出ない。

項の条件だけでは閉じない:

- 出力が両方標準形でも sp は単調でない（像の部分項からの乱択 199,900 組で 5 組）。例: a = 0 で ψ_0(ψ_0(X))（X ≥ Ω_1）を sp は ψ_0(X) に潰す。
  こうした入力は標準形の行列から来ない（`bms -s` で (0,0,0)(1,0,0)(2,1,0) は標準形でない）。
- 2 行では「各添字 a について、像の中で ψ_a の下に現れる引数の集合」の上で sp は狭義単調（105,260 組で反例 0）。
  3 行では 121 件崩れる（別々の行列から来た引数どうし）。
- 2 行でも「子の添字 ≤ 親の添字 + 1」という項の条件だけでは崩れる（乱択で 8,931/115,665）。実際、この条件を満たす生の項には
  無限下降列 ψ_0(ψ_1(X_k))、X_0 = Ω_2、X_{k+1} = ψ_0(ψ_1(X_k)) がある（X_1 は (0,0,0)(1,1,0)(2,0,0)(3,1,0)(4,2,0) の読みで、標準形でない）。

違いの道を行列の列に対応づけると（n ≥ 1、2 行 11,539 組・3 行 11,769 組）:

- 引数の段はすべて M と M[n] で**同じ番号の列**を通る（列の子の並びの j 番目どうしを比べ、その子へ降りる）。
- 底は、2 行では q = P_0(x) での打ち切り（7,301）か、列 x と最初のコピーの根 r⁽¹⁾（M[n] では同じ番号）の添字の違い（4,121）。
  3 行では大半（9,581）が q の祖先の列の添字 v の違い（上げ・上に乗る子を通じて v が下がる）、ほかに x と r⁽¹⁾ の添字（920）、
  q での打ち切り（748）、q の添字（428）。

つまり (1b) は lean-yapss の第 5 章（整礎性）に当たる部分で、比べる 2 つの項が同じ行列の展開から来るという関係（違いの道の文脈）を使う必要がある。

## 段 1 の証明の部品（現時点の見取り図）

**項の側（Lean）**
- 和の単調性と標準形の保存（済、`Arith.lean`）、sf は標準形の上で恒等（済、`SF.lean`）、
  ω 冪の標準形の保存と狭義単調性（済、`Omega.lean` の `isOT_omega`・`omega_lt_omega`）。
- 違いの道の持ち上げ（済、`SP.lean`）: sp の 1 段 `step` と最後の状態 `spArg`（sp a b c = ψ_a(spArg a b c)）。
  - `frame_same`: 共通の状態 b、次の加数が ψ_s(y_u) < ψ_s(y_w)（添字が同じ）、小さい側の残りの先頭 ≤ ψ_s(y_u) なら、
    step のあとに残りを連結したものは真に小さい。場合は「両方書き換え」（H の狭義単調性 `H_lt_H`）、
    「大きい側だけ書き換え」（b < y_w ≤ H(y_w)、`le_H`）、「どちらも書き換えない」（`add_app_lt`）。
    小さい側だけ書き換えることはない（y_u < y_w なので）。
  - `frame_prefix`: 小さい側の和が先に終わる段。
  - `spArg_frame_same`・`spArg_frame_prefix`: 残りの加数が書き換えを起こさない（spArg = 連結）ことを仮定に置いた形。
  - `spArg_frame_diff`（添字が違う段）: 次の加数が c_u < c_w（添字は任意）のとき、W0 = b + c_w として
    (i) 小さい側の残りの加数はすべて W0 のどの加数よりも小さい、(ii) 小さい側で書き換えうる加数 ψ_s(y)（s ≥ a、b < y）が作る状態 H は
    「どんな続き R でも H ++ R < W0」（`SB H W0`）、(iii) 大きい側の残りは書き換えない、なら真に小さい。
    状態の不変条件 `SB σ W0` が、書き換えない段で保たれる（`SB_add`）ことで示す。
  - 書き換えない残り（`spArg_eq_app`）: 残りの各加数 ψ_s(y) が y ≤ b か s < a で、b ++ 残り が標準形なら、sp は連結するだけ。

### 訂正（2026-10-02）: 3 行の標本は SRO より下に限る
