## 1. 対象

**trio 列** = 3 つ組 `(a, b, c)` の有限列。`a` を行 0（深さ）、`b` を行 1、
`c` を行 2 と呼ぶ。列 `j` の**レベル**を

```
lev(M, j) := 2 * b_j + c_j
```

**親**: 列 `j1` の行 `i` の親 `parent(M, i, j1)` は、行 `i-1` の祖先鎖をたどって
最初に行 `i` の値が真に小さくなる列（行 0 では「直前の、真に浅い列」）。存在
しないこともある。`srow(M, j) := max{i | 行 i の値 > 0}`（全部 0 なら 0）。

**展開** `M[n]`（BM4）: 末尾列 `x = |M|-1` を見る。
- 全行 0、または `parent(M, srow(M,x), x)` が無い ⟹ `M[n] = M` から末尾を除く
- 親 `j0` があれば、`delta_i := (M[x]_i - M[j0]_i)`（`i < srow` のみ、それ以外 0）
  として、`M[0..j0-1]` の後ろに `M[j0..x-1]` の**コピーを n 個**並べる。
  コピー `k` では、行 `i` の祖先鎖で `j0` の子孫になっている列にだけ
  `k * delta_i` を足す

**行 2 は決して増えない**（`delta_2 = 0`）。`z<2` 断片では `c_j ∈ {0,1}`。

## 2. `W` と `Wself`

`W_u`（`u ∈ N`）は反復帰納的に定義される trio 列の集合族（Buchholz 流）。
`Aop(W, u, X, M)` を次の 3 分岐の選言とし、`W_u := lfp(X |-> {M | Aop(W,u,X,M)})`
を段 `u` について再帰的に取る:

1. `|M| <= 1` かつ `lev(M,0) = 0`
2. `forall n >= 1, M[n] ∈ X`
3. `exists m < u`: 末尾列が親を持たず `lev(M,|M|-1) = m+1` で、かつ
   `forall z ∈ W_m`（`z` の根の深さは 0）, `graft(M,z) ∈ X`
   （`graft(M,z)` = `M` の末尾列を、深さを合わせた `z` に差し替える）

**証明済みの事実**: `M ∈ W_u  <->  M ∈ Wself  かつ  lev(M,0) <= u`。ここで
`Wself := {M | M ∈ W_{lev(M,0)}}`。つまり段はちょうど根のレベルで決まる。

**停止性との関係**: 「すべての標準形 `M` が或る `W_u` に属する」＋（証明済みの）
共終性 ⟹ trio 停止性。

## 3. 残核

```
S ∈ Wself,  0 <= p < |S|,  C ≠ [] ,  C ∈ Wself,  lev(C,0) <= lev(S,p),
C の根の深さ = S の列 p の深さ,   C の全列の深さ >= それ,
R := S[0..p-1] ++ C ++ S[p+1..]  とおく。

さらに次を仮定する:
  (i)  R の末尾列は R の中で親を持つ
  (ii) その末尾列は、自分の属するブロックの中では親を持たない
       （S[p+1..] が空なら「C の中で」、空でなければ「S[p+1..] の中で」）
  (iii) R から末尾列を除いた列に、行 2 > 0 の列が少なくとも 1 つある

このとき  R ∈ Wself。
```

一言でいうと: **`W` 元のある列の下に、その列のレベル以下で停止するブロックを
吊るしてよい**。ただし (i)(ii) は「**文脈がブロック内の孤児を復活させる**」場合に
限る、という意味（それ以外の場合は証明済み）。

`W` の定義の分岐 3 と比べると、違いは 2 点だけ:

| | 分岐 3 | 残核 |
|---|---|---|
| 位置 | 末尾列のみ | 任意の位置 |
| ブロックの段 | `lev - 1` | **`lev`**（1 つ上） |
