# trio 停止性の残核 — 単体で読める問題文

`PROOF-STATUS.md` の残核 `Subst1gReviveSelf` を、Lean を知らなくても読める形に
書き下したもの。これ 1 本を証明すれば 3 行バシク（BM4, `z<2` 断片）の停止性が
出る（残りは全部 Lean で証明済み・`sorry` 0）。

## 1. 対象

**trio 列** = 3 つ組 `(a, b, c)` の有限列。`a` を行 0（深さ）、`b` を行 1、
`c` を行 2 と呼ぶ。列 `j` の**レベル**を

```
lev(M, j) := 2 * b_j + c_j
```

**親**: 列 `j1` の行 `i` の親 `parent(M, i, j1)` は、行 `i-1` の祖先鎖をたどって
最初に行 `i` の値が真に小さくなる列（行 0 では「直前の、真に浅い列」）。存在
しないこともある。`srow(M, j) := max{i | 行 i の値 > 0}`（全部 0 なら 0）。

**展開** `M[n]`（BM4）: 末尾列 `x = |M|-1` を見る。
- 全行 0、または `parent(M, srow(M,x), x)` が無い ⟹ `M[n] = M` から末尾を除く
- 親 `j0` があれば、`delta_i := (M[x]_i - M[j0]_i)`（`i < srow` のみ、それ以外 0）
  として、`M[0..j0-1]` の後ろに `M[j0..x-1]` の**コピーを n 個**並べる。
  コピー `k` では、行 `i` の祖先鎖で `j0` の子孫になっている列にだけ
  `k * delta_i` を足す

**行 2 は決して増えない**（`delta_2 = 0`）。`z<2` 断片では `c_j ∈ {0,1}`。

## 2. `W` と `Wself`

`W_u`（`u ∈ N`）は反復帰納的に定義される trio 列の集合族（Buchholz 流）。
`Aop(W, u, X, M)` を次の 3 分岐の選言とし、`W_u := lfp(X |-> {M | Aop(W,u,X,M)})`
を段 `u` について再帰的に取る:

1. `|M| <= 1` かつ `lev(M,0) = 0`
2. `forall n >= 1, M[n] ∈ X`
3. `exists m < u`: 末尾列が親を持たず `lev(M,|M|-1) = m+1` で、かつ
   `forall z ∈ W_m`（`z` の根の深さは 0）, `graft(M,z) ∈ X`
   （`graft(M,z)` = `M` の末尾列を、深さを合わせた `z` に差し替える）

**証明済みの事実**: `M ∈ W_u  <->  M ∈ Wself  かつ  lev(M,0) <= u`。ここで
`Wself := {M | M ∈ W_{lev(M,0)}}`。つまり段はちょうど根のレベルで決まる。

**停止性との関係**: 「すべての標準形 `M` が或る `W_u` に属する」＋（証明済みの）
共終性 ⟹ trio 停止性。

## 3. 残核

```
S ∈ Wself,  0 <= p < |S|,  C ≠ [] ,  C ∈ Wself,  lev(C,0) <= lev(S,p),
C の根の深さ = S の列 p の深さ,   C の全列の深さ >= それ,
R := S[0..p-1] ++ C ++ S[p+1..]  とおく。

さらに次を仮定する:
  (i)  R の末尾列は R の中で親を持つ
  (ii) その末尾列は、自分の属するブロックの中では親を持たない
       （S[p+1..] が空なら「C の中で」、空でなければ「S[p+1..] の中で」）
  (iii) R から末尾列を除いた列に、行 2 > 0 の列が少なくとも 1 つある

このとき  R ∈ Wself。
```

一言でいうと: **`W` 元のある列の下に、その列のレベル以下で停止するブロックを
吊るしてよい**。ただし (i)(ii) は「**文脈がブロック内の孤児を復活させる**」場合に
限る、という意味（それ以外の場合は証明済み）。

`W` の定義の分岐 3 と比べると、違いは 2 点だけ:

| | 分岐 3 | 残核 |
|---|---|---|
| 位置 | 末尾列のみ | 任意の位置 |
| ブロックの段 | `lev - 1` | **`lev`**（1 つ上） |

## 4. 分かっていること

**証明済みの断片**（`sorry` 0, axioms clean）:
- 行 2 が恒等的に 0 の列は全部 `Wself`（＝ 2 行バシクの停止性。lean-yapss を
  取り込み済み）
- 行 2 ≡ 0 のブロックの末尾に**任意の 1 列**を継いでよい
- `W` は接頭辞閉・接尾辞閉（接尾辞自身の根のレベルで）・区間閉
- 段はちょうど根のレベル / `Wself` は展開で閉じる
- 上の (i)(ii)(iii) を落とした場合（mirror / orphan / 端置換 / 行 2 ≡ 0）

**経験的検証**: 上位命題で 210201 例 0 違反、残差ケースのみ乱択 78885 例 0 違反。
⚠ ただし本物の ST_TS 行列では `W` 所属の判定自体が停止性問題なので、
判定できたのは 651 例まで。**決定的な検証ではない**。

## 4.5 残核に**追加で渡せる**仮定（未実装だが実在する）

残核は `subst1g_of_revive` / `end_subst_of_revive` の帰納の中から呼ばれており、
呼び出し地点では以下が**手元にある**。今は捨てているが、渡すように Lean を
書き換えるのは小さい作業なので、証明でこれらが要るなら遠慮なく使ってよい。

**`S[p+1..] ≠ []` の場合**（ホスト `S` のデータで帰納している）:
- `S` の全**真の接頭辞** `S[0..k-1]`（`k < |S|`）について、同じ置換命題が成り立つ
- `S` の `Aop` データ 1 段:
  - 分岐 2 なら「すべての `n >= 1` について `S[n]` に同じ置換命題」
  - 分岐 3 なら「`S` から末尾を除いた列に同じ置換命題」
  - 分岐 1 は `|S| <= 1` なのでこの場合は起こらない

**`S[p+1..] = []` の場合**（ブロック `C` のデータで帰納している）:
- `C` の全真の接頭辞 `C[0..k-1]` について「`S` から末尾を除いた列 ++ それ」が `Wself`
- `C` の `Aop` データ 1 段（同様に分岐 2 / 3）
- `S ∈ Wself` そのもの（`S` のデータは無い）

つまり残核は「**帰納の 1 ステップ**」であって、孤立した命題ではない。

これを `N := S.take (p+1)` に当てると `N.drop (p+1) = []` なので結論はちょうど


⟹ **主枝（`S.drop (p+1) ≠ []`）では、残核の「置換」部分は証明すべきことでは

## 4.8 残核の**同値な顔**（翻訳しても進まない）

以下はすべて互いに帰着し合う。翻訳作業に時間を使わないこと。

| 顔 | 内容 |
|---|---|
| `Subst1gReviveSelf` | 文脈がブロック内孤児を復活させる置換（Lean の残核） |
| `(GC)` | `S ∈ W u` かつ `domT S m` ⟹ `∀ z ∈ W m` based, `graft S z ∈ W u`（＝ 節 3 の閉包が所属から無料で出るか）計測 1221万例 0 違反 |
| `(LOW)` の親あり半分 | `A ++ [c] ∈ Wself`, `lev t <= lev c`, 同深さ ⟹ `A ++ [t] ∈ Wself`（孤児半分は `snoc_orphan` で証明済み）計測 554万例 0 違反 |
| `(TOW)` / `(WL)` | シフトコピー塔 / 行 1 リフトの段法則（`e = 0` は `W_flatMap_copies` で無料、`e > 0` が本体） |
| `(REPL)` | 接尾辞を同じ根レベルの別物に差し替えてよい 計測 110万例 0 違反 |
| `(SNOC)` | `W u` 元に 1 列足してよい |

`(TOW)` の `|Q| = 2` の形（実機で確認）: 末尾列の親は最後のコピーの根なので
`T_n[m] = T_{n-1} ++ (m 列の対角)`。逆向きの漸化式 `T_n = Q ++ shiftr01 e 0 T_{n-1}`
に `oper_append_inner` を当てると `n >= 3` で
`T_n[m] = Q ++ shiftr01 e 0 (T_{n-1}[m])`。どちらも
**「`Q` の後ろに、根レベルの等しい `Wself` 元を深く継ぐ」**に落ちる（＝ 貼り合わせ）。

`(TOW)` が**無料になる場合**（＝ 内容は `|Q| >= 2` かつ行 2 の列あり）:
`Q` が行 2 ≡ 0 なら塔も行 2 ≡ 0、`|Q| = 1` なら塔は定数対角、`e = 0` なら同一コピー。

**なぜ全部同じか**: どれも「`W u` 元の接尾辞の上に、ガード付きコピー塔を建てて
良いか」に落ちる。塔の背骨（対角）はペア定理で `W` に入るが、背骨の各列の下に
コピーを吊るす操作がまさに残核。

## 4.9 壁の機構（2026-08-09 に判明した最も鋭い言い換え）

trio が 2 行バシクと違う点は**ただ一つ**、行 2 の崩壊がコピーの行 1 を持ち上げる
ことである。そのリフト法則が `(WL)`。ここで次の対立が本質:

* BM4 が実際に施すリフトのマスクは `A_xy` ＝ 悪い根の**添字**の子孫錐。
* 証明済みのリフト法則（階段リフト）のマスクは行 1 の**値**（`amin` の上方集合）。

`amin` は展開で不変なので値マスクのリフトは展開と可換。一方**添字**で決まる錐は
コピーで壊れる（コピー `k` は自分自身の錐を持つ）ので、`Lift1` は展開と可換で
ない（親あり枝 192996 例中 47718 例で不可換。悪い根が内部にある `j0 ≥ 1` の
93231 例では**すべて可換**）。

2 つのマスクの差はちょうど**行 1 のタイ**（根と行 1 の値が等しい列）で、
タイが無ければ `(WL)` は既証の法則から**無料**（Lean 済み）。そして

* 実 ST_TS の行 2 悪い部分では `v0 ≥ 1` のタイは **4044 万例で 0**、
* しかし既に証明済みの局所不変量（`r1ok`/`z0ok`/`noninc`/`zle1`）では**排除できない**
  （反例 `[(0,0,0),(1,1,0),(2,1,0),(2,2,1)]` は不変量を満たすが ST_TS ではない）。

⟹ **タイ無しは ST_TS 到達可能性そのもの**。`W` の枠組みは ST_TS を仮定しない
設計なので、この経路では埋まらない。残核 `Subst1gReviveSelf` 自身は
（不変量を課さない乱択でも 0 違反なので）**一般に真**と見られ、ST_TS を必要と
しない。したがって攻めるべきは残核そのもの。
