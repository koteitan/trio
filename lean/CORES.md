### ⚠⚠ R94（R2, commit `89d6ae8`）: **この「違反 0」は空虚である**

> **健全な反証器が確定 `False` を返す ⟺ `lev S 0 > a`。それ以外の非所属は原理的に検出できない。**

理由（定義からの算術。測定不要）: `oper`（`Trio.lean:98`）は**第 1 列を絶対に落とさない**。

    j1 = 0             → `M` そのもの
    末尾が全零 / 親なし  → `Pred M = M.dropLast`（`|M|>=2` なので第 1 列は残る）
    それ以外            → `M.take j0 ++ (range n).flatMap ...`
                          `j0>=1` なら先頭は `M[0]`。**`j0=0` でも flatMap の
                          `k=0, j=0` の項が `(entry M 0 0 + 0*d0, …) = M[0]`**

⟹ 木のどのノードも先頭列は `S[0]` ⟹ **到達する単元は `[S[0]]` だけ** ⟹
反証器は `lev S 0 > a` のときにしか鳴らない。
（`Wset.lean:2161` `lev_root_le_of_mem_W` の docstring と同じ内容。
`Wtower2.lean:2990` `mem_Wself_iff`（無条件・緑）: `M ∈ W u ⟺ M ∈ Wself ∧ lev M 0 <= u`
＝ **段の情報はすべて根にある**。`Wself` 側は最小不動点なので有限の検査では偽を示せない。）

実測: 乱択 40,000 件で **`False` と `lev S0 > a` の不一致 0 件**、先頭列の保存 80,000/80,000。

**⟹ 上の表のどの核が反証不能かは、走らせる前に分かる。**
「仮定が `X ∈ W u` を与え、結論が `Y ∈ W u` で `lev Y 0 = lev X 0`」なら
`lev_root_le_of_mem_W` より `lev Y 0 <= u` が**仮定から自動** ⟹ **絶対に鳴らない**:

    `WCat`（`A ++ B` の根は `A` の根）/ `WSnoc`（`C ++ [p]` の根は `C` の根）
    `CoreCap` ＝ `CoreSingleton`（結論の根 `(0,v+t,z)`、`lev = 2(v+t)+z <= a` は前提そのもの）
    `TowerOK` / `TowerOK2`（結論は `(0,v,z) :: …`）
    ⟹ **これらの「違反 0」は情報を持たない。**

**陰性対照「段 −1」が 100% 鳴るのも同じ理由**（段を 1 下げると `lev S 0 > a` そのもの）。
⟹ この対照は「反証器が鳴ること」を示すが「**根の段以外を見られること**」は示さない。
⟹ 教訓 12 の対照としては**不十分**。

⟹ **鳴りうるのは結論でリフトや置換が根を持ち上げる形の核だけ**（`LiftStage` 系、`Subst*` の一部）。
H12 の §146（`v=0` / `b=1` が原理的に未判定）は、この定理の実測側の現れ。

### ⟹ 結論

> **健全な反証器は存在するが、我々が気にしている核のすべてに対して盲目である。**
> なぜなら我々の核はどれも「**段を保つ**」形に設計されているから。
