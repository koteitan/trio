## ★★★★★★ 証明の手筋 —— **最小性を「破らせない」のではなく「親の位置を突き止める」のに使う**

```lean

    (hr0 : ∀ l, 0 < l → l < Q.length → entry Q 0 0 < entry Q 0 l) :
    ∀ m k, k ≤ m → m < n → le0 (mTower Q d e n) (k * Q.length) (m * Q.length)
```

    **4** 1 歩で `(k+1)*|Q|` へ、そして `le0_trans`

> **★★★ 「**最小性が破れないようにするのではなく、最小性を使って親の位置を突き止める**」**
> **⟹ これで `+d` の要求が**消える**。`0 < d` だけで済む。**
