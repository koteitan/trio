## 0. 記号（`W` が 3 つあるので注意）

| 記号 | 意味 |
|---|---|
| `W u` | **反復帰納的集合**（Lean の `def W (u : ℕ) : Set TrioSeq`）。この断片では `W 0` だけ使う |
| `W_w`, `W_2`, ... | **順序数**。シートの psi 記法のなか（`psi(W_w + psi_1(W_2))` など）にだけ出る |

展開は行列ごとに違うので、族に新しい名前は付けず **`X[n]`** と書く
（`X` は行列、`n` は自然数）。添字は `bms` の括弧と同じ:

```
X[0] = 良い部分 ++ 悪い部分×1        Lean の X⟦1⟧
X[n] = 良い部分 ++ 悪い部分×(n+1)    Lean の X⟦n+1⟧
```

用語は定義文書（`~/proofs/papers/koteitan/Koteitan_バシク行列の数式的定義...html`）
の **良い部分 `G = S_0...S_{r-1}` / 悪い部分 `B(a)` / bad root `r = P_t(X-1)`** に合わせる。

証明側だけの言葉:

| 言葉 | 意味 |
|---|---|
| **土台** | `A ++ M ++ (載せる物)` の `A`。証明で選ぶ切り方で、定義文書には無い |
| **のりしろ** | 同じく `M`。1 列目の高さが「土台のレベル + 1」 |

土台とのりしろは「ブロックを載せた行列の bad root がちょうど境目に来る」ように選ぶ。

`X↑d` は行 0 に `d` を足す（`shiftr01 d 0`）。`X^n` は `X` を `n` 個つなげる。

## 3. 行293 の形と、詰まる 1 点

行293 = `X(1,1,0)(2,2,0)(3,2,0)`。展開は

（`R293_mem_of_tower`、緑。Lean 側は `Mtwd 2 Q N293 (n+1)`）。


`R293[n]` の最後の列は高さ `2n+2`。以下 `d := 2n+2` と書く。

- `(d+1,1,0)` の行 1 の親は**根**。塔は `TwD (d+1) R293[n] m`。→ `R293[n]` を
  高さ `d+1` で吊るせること（＝レベル `d`）が要る。
- `(d+2,2,0)` の行 1 の親は直前の `(d+1,1,0)`。塔は鎖
  `R293[n](d+1,1,0)(d+2,1,0)...`。→ 同じくレベル `d` から。

`Lv` のレベルは**最後のセグメントの頭の高さ**なので、`R293[n]`（最後の列は高さ `d`）を
レベル `d` にするには最後のセグメントを `[(d,2,0)]` に取るしかない。その記録には

> **(G2)** 任意の梯子の頭 `A`（レベル `c`）に対し `A ++ [(c+1,2,0)] ∈ W 0`

### (G2) が要るもの

## 4. ランクは上げられない（証明付き）

```
Lv (r+1) (a+1) A = Aok A ∧ ∃ A0 M, A = A0 ++ M ∧ Lv r a A0 ∧ MidD (a+2) M
                   ∧ (∀ s A', Lv r (a+s) A' → A' ++ M↑s ∈ W 0)     ← 再継ぎ性
```

再継ぎ性が `Lv` を**負の位置**で、しかも**添字 `a+s ≥ a+1`** で参照する。

- 素直な再帰（ランク無し）: 停止しない
- 帰納的述語: 負の出現があるので不可
- 最小不動点: 混合変位で単調でない
- **測度による整礎帰納法も不可**: 構造再帰の呼び出しは `a` が減る方向、
  再継ぎ性の呼び出しは `a` が増える方向。1 つの測度で両方を減らせない。

ランク `r` を足すと定義は通るが、

- `Lv r a A → r ≥ a`（記録を 1 段ほどくたびに両方 1 減る）
- ⟹ `Lv r (a+s) A'` は `s > r - a` で**空**。再継ぎ性はそこまでしか効かない
- **ランク単調性 `Lv r a A → Lv (r+1) a A` は偽**。証明には再継ぎ性の仮定側で
  逆向き `Lv (r+1) c A' → Lv r c A'` が要るが、`Lv 1 1 A → Lv 0 1 A = False`

### 逃げ道: ランクを ∃ で包む（`Lw`、実装済み）

`Lw c A := ∃ r, Lv r c A`。`Lv r' c A' → Lw c A'` は自明なので、

> 「**`Lw` の頭すべてに継げる**」という**定理**は、任意のランクの記録の再継ぎ性として使える

`Seg a M`（`MidD (a+2) M` ＋ 頭の行 1 < 2 ＋ `Lw` に対するシフト再継ぎ）を作り、
`Lw_tower` で塔が回る。`Seg a [(a+1,1,0)]` は `Lv_snoc` から出る（`Seg_one`）。

これで **`M` が `(·,1,0)` 1 列のときの (G2) は解けた**（`Seg_snoc2` = `Lv_snoc2`）。

## 5. それでも (G2) が解けない理由

(G2) を梯子の記録に入れるには、セグメント `[(c+1,2,0)]` の再継ぎ性

> `∀ s A', Lw (c+s) A' → A' ++ [(c+1+s,2,0)] ∈ W 0`

が要る。これは (G2) そのもの（**自己参照**）。しかも `Lw` の頭は最後のセグメントの
頭の行 1 が 2 でもよいので、**(G2) は `Lw` の頭全体では偽**。

段階化（`L^0 ⊆ L^1 ⊆ ...`、`L^{j+1}` の再継ぎ性は `L^j` の頭に対する主張）を試すと、
(G2) は `L^j`（j≥1）の頭では解けるが、`L^{j+1}` の記録に `(·,2,0)` を入れるには
`L^j` の頭に対する (G2) が要り、その `L^j` の記録に入れるには `L^{j-1}` …と
**必ず `L^0` に落ちて**、そこでは解けない。

### 部分的な突破: `hang2`（実装済み）

記録を作るのを諦め、**吊るしだけ**を直接示す:

```
hang2 : Lw a A0 → Seg a M → ∀ B, Bok B →
          (A0 ++ M ++ [(a+2,2,0)]) ++ B↑(a+3) ∈ W 0
```

`blkD_memS` の `Mid` を `(a+2,2,0)` 自身に取り、不変量を

```
P s X := ∃ X0 M', X = X0 ++ M' ∧ Lw (a+s) X0 ∧ Seg (a+s) M'
```

にする。`hbase` は `Seg_snoc2`、`hclose` は「`Seg` を `Blk` で伸ばしても `Seg` のまま」
（`MidD_append` ＋ 再継ぎ性は `Seg.reapp` と `hIH` の合成）で閉じる。系として

```
hang2_tw   : ∀ n, TwD (a+3) (A0 ++ M ++ [(a+2,2,0)]) n ∈ W 0
hang2_snoc : A0 ++ M ++ [(a+2,2,0)] ++ [(a+3,1,0)] ∈ W 0
```

`R292_snoc310` はその実例（`R293[0] ++ (3,1,0)`）。

**繰り返せない理由**: `hang2` の結論は「吊るせる」であって `Lw (a+2) (...)` ではない。
次の段（`R293[1]`）には `Lw 2 R292` が要り、それは (G2) に戻る。

## 7. 詰まりの最終形

塔の各段は「**その塔の頭が属するクラス自身**に継げるセグメント」を要求する。
そのクラスは `(·,2,0)` で終わる頭を含まねばならず、その所属を示すには塔が要る。

```
(·,2,0) で終わる頭 ∈ クラス C   ⟸  塔        ⟸  C に継げるセグメント  ⟸  C の定義
```

段階化（`C_0 = Lw`、`C_{k+1}` は `C_k` の頭に対する再継ぎ性を持つ）は
`C_{k+1}` が**セグメント継ぎ足しで閉じない**ため回らない。閉じるように
足すと再継ぎ性が `C_{k+1}` を添字 `c+s`（増える方）で参照して定義不能になる。

## 8. 次に試す候補

1. **`hang2` の底を意味的述語にする**。`Lw a A0` の代わりに
   `Hd c A := Aok A ∧ Ancd (c+1) A ∧ (∀ B, Bok B → A ++ B↑(c+1) ∈ W 0)` を使えれば
   結論と仮定が同型になり繰り返せる。障害は `Lw_tower` が `Lv` の記録
   （`MidD_append` による閉包）を使うこと。`Hd` は `blkD` の `hclose` で閉じない。
   → 「`Hd` ＋ 最後のセグメントの分解」を持つ構造的述語で閉包を取り直せるか。
2. **順序数による整礎帰納法**。塔は `Z ++ [c]` の基本列の項なので、
   `W` の最小不動点の帰納法と噛み合わせる形を探す。
3. **`Ld`（s=0 のみ、ランク無し）への refactor**。
   `Ld (a+1) A := Aok A ∧ ∃ A0 M, A = A0++M ∧ Ld a A0 ∧ MidD (a+2) M
   ∧ (∀ A', Ld a A' → A' ++ M ∈ W 0)` はレベルの構造再帰で定義でき（ランク不要）、
   `Lv_hang` は `P s X := (s = 0 ∧ Ld a X)` でそのまま通る。
   いま使っている `Lv` の ∀s は実質 s=0 しか効いていないので、機能は落ちない。
   掃除としては有効（(G2) は解けない）。
