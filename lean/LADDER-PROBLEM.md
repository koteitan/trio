## 3. 詰まっている点 — 梯子はインピーディカティブ

行293 以降で要るのは 2 つの継ぎ足しだけ:

```
(A) Z ++ [(D,1,0)]   行 1 の親 = 根          塔 = TwD D Z m = Z ++ Z↑D ++ Z↑2D ++ ...
(B) Z ++ [(D,2,0)]   行 1 の親 = 直前の列     塔 = Mtw Y0 M m = Y0 ++ M ++ M↑1 ++ ...
```

(B) は `snocY_mem` で済む。問題は塔の依存が循環すること:

```
(A) 深さ D   → 塔を作るには Z に深さ D のブロックを吊るす
             → アンカーは Z の末尾 (D-1,*,0) → 底は「(D-1,*,0) を継ぐ」= (A)/(B) 深さ D-1   ↓
(B) 深さ L+1 → 塔 Mtw の M↑k の先頭 (L+k,1,0) を継ぐ = (A) 深さ L+k                        ↑
```

両方を同時に回す不変量が要る。それが梯子

```
Lv a A = Aok A ∧ ∃ A0 M, A = A0 ++ M ∧ Lv (a-1) A0 ∧ MidD (a+1) M
                ∧ (∀ s A', Lv (a+s) A' → A' ++ M↑s ∈ W 0)      ← ここ
```

だが、最後の再継ぎ性が `Lv` を**負の位置**で、しかも**添字 `a+s ≥ a`** で参照する。

- 素直な再帰: 停止しない（Lean が拒否）
- 帰納的述語: 負の出現があるので不可
- 最小不動点: 混合変位で単調でない
- **ランク `r` を足す**（`Lv r a A`、再継ぎ性は `Lv (r-1)` を参照）: 定義は通る。
  だが塔を 1 段作るたびにランクが上がる（`Lv_shift : Lv r → Lv (r+1)`）ので、
  次の段に渡せない。**硬すぎて使えない。**
- 族 `K` でパラメタ化: `K` に分解（hKstep）と構成（hKintro）の両方が要り、
  結局 `K` は梯子そのもの。インピーディカティビティが戻る。

`blkD_mem` / `blkD_memS` / `blkD_stage` の `P` はパラメータなので同じ問題を
起こさない。梯子だけが「述語として定義したい」ために詰まる。
