# bms-rathjen — BM4-Analysis シートの正規化コピー

[← 戻る](../README.md) | [Japanese](README.md) | [English](README-en.md)

`~/proofs/papers/BM4-Analysis-2021.4.27.xlsx` の「To psi(I)」シートを
機械可読な形式に正規化したコピー。生成: `tools/normalize_sheet.py`。

**形式だけを直している。順序数の値・行列は一切変更していない。**

## `to-psi-I.tsv`

| 列 | 内容 |
|---|---|
| `row` | シートの行番号 |
| `matrix` | BMS 行列（シートの A 列そのまま） |
| `label_orig` | ラベル（シートの B 列そのまま） |
| `label_norm` | 正規化したラベル |
| `fix` | 適用した規則（カンマ区切り、無修正なら空） |

ラベル付き 4769 行のうち **288 行**に形式修正がある。

## 正規化の 3 規則

1. **別名併記** (`aliasN`) — `A = B = C` を分割し、`psi(W...)` 形の最初の別名を
   正規形とする（無ければ最初の別名）。217 行。
   例: 行 180 `psi(W_2) = psi(psi_2(0)) = psi(psi_I(1))` → `psi(W_2)`。
2. **括弧不整合** (`paren+n` / `paren-n`) — 別名ごとに、不足する `)` を末尾に足し、
   末尾の余分な `)` を落とす。72 行。
   例: 行 2144 `psi(W_(w^(w2))` → `psi(W_(w^(w2)))`。
3. **先頭タイポ** (`typo`) — `si(` で始まるラベルを `psi(` に直す。1 行。
   例: 行 4522 `si(W_(W_W_2+W_3))` → `psi(W_(W_W_2+W_3))`。

[ebp2bms](../ebp2bms-1.md) の生成器で再現できる行が **225 → 231** になった。

| 261 | $`4`$ | 別名 |
| 265 | $`5`$ | 別名 |
| 266 | $`6`$ | 別名 |
| 2144 | $`\omega^{\omega\cdot 2}`$ | 括弧 |
