# bms-rathjen — a normalized copy of the BM4-Analysis sheet

[← Back](../README.md) | [Japanese](README.md) | [English](README-en.md)

A copy of the "To psi(I)" sheet of `~/proofs/papers/BM4-Analysis-2021.4.27.xlsx`,
normalized into a machine-readable form. Generated by `tools/normalize_sheet.py`.

**Only the format is fixed; no ordinal value and no matrix is changed.**

## `to-psi-I.tsv`

| column | contents |
|---|---|
| `row` | row number in the sheet |
| `matrix` | the BMS matrix (column A verbatim) |
| `label_orig` | the label (column B verbatim) |
| `label_norm` | the normalized label |
| `fix` | which rules were applied (comma separated; empty when untouched) |

Of the 4769 labelled rows, **288** carry a format fix.

## The three normalization rules

1. **Alias lists** (`aliasN`) — split `A = B = C` and take the first alias of the form
   `psi(W...)` as canonical (the first alias otherwise). 217 rows.
   Example: row 180 `psi(W_2) = psi(psi_2(0)) = psi(psi_I(1))` → `psi(W_2)`.
2. **Unbalanced parentheses** (`paren+n` / `paren-n`) — per alias, append the missing
   `)` or drop the surplus trailing `)`. 72 rows.
   Example: row 2144 `psi(W_(w^(w2))` → `psi(W_(w^(w2)))`.
3. **Leading typo** (`typo`) — a label starting with `si(` becomes `psi(`. 1 row.
   Example: row 4522 `si(W_(W_W_2+W_3))` → `psi(W_(W_W_2+W_3))`.

## Effect

`tools/omega_alpha_rows.tsv` (the extraction of the pure $`\psi_0(\Omega_\alpha)`$ rows) is
built from this file. Normalization raises the pure-row count from 812 to 813 and the number
of rows the [ebp2bms](../ebp2bms-1-en.md) generator reproduces from **225 to 231**. The six
rows gained are:

| row | $`\alpha`$ | rule |
|---|---|---|
| 180 | $`2`$ | alias |
| 241 | $`3`$ | alias |
| 261 | $`4`$ | alias |
| 265 | $`5`$ | alias |
| 266 | $`6`$ | alias |
| 2144 | $`\omega^{\omega\cdot 2}`$ | paren |

## What is not fixed

Rows where the matrix and the label disagree (1947 / 2113 / 2131 / 2133 and the others
recorded in [dom.md](../dom.md)) are not a format problem, so they are left alone.
