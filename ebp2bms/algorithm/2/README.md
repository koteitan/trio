# 拡張ブーフホルツ psi ↔ トリオ数列 アルゴリズム: ε₀ ≤ α < Λ

[← 戻る](../../../README.md) | [Japanese](README.md) | [English](README-en.md) | [α < ε₀](../1/README.md) | [ε₀ ≤ α < Λ](README.md)

$`\psi_0(\Omega_\alpha)`$ に対応するトリオ数列（z<2 断片）の標準形行列を作る一般式、$`\varepsilon_0 \le \alpha \lt \Lambda`$（$`\Lambda`$ = 最小 $`\Omega`$ 不動点）。

具体的な行列は[対応表](../../sheet/2/README.md)にある。

[α < ε₀ 版](../1/README.md)の文法と**同一**で、変わるのは指数スロットの中身だけである。
$`\alpha = \sum_i \omega^{\beta_i}`$、$`1 + \beta_i' = \beta_i`$、
$`\beta_i' = \sum_j \omega^{\gamma_{ij}}`$ と 2 段組みに書き、加算項を加算ユニットとして並べる。

```math
M(\alpha) = U_1 +\!\!+ U_2 +\!\!+ \cdots +\!\!+ U_m .
```

### 構造

- 加算ユニット $`U_i = \omega^{\beta_i}`$
  - アンカー
  - 根 — $`\beta_i`$ の先頭の $`1`$ を担う
  - 乗算ユニット $`S_{ij} = \omega^{\gamma_{ij}}`$
    - 桁
    - **OT 埋め込み** $`\mathrm{B}(\gamma_{ij})`$
- 加算ユニット $`U_i = 1`$（$`\beta_i = 0`$ のとき）
  - アンカー
  - z0 列

[α < ε₀ 版](../1/README.md)との違いは 1 点だけ: 乗算ユニットの下が
「原始数列埋め込み $`\mathrm{PrSS}`$」から
「**OT 埋め込み** $`\mathrm{B}`$」に一般化される。
$`\gamma \lt \varepsilon_0`$ では $`\mathrm{B}(\gamma) = \mathrm{PrSS}(\gamma)`$ なので
α < ε₀ 版は本ページの特殊ケースである。

### 加算ユニット（加法）

α < ε₀ 版と同一。状態 $`r`$（直前の加算ユニットの根の $`x`$ 座標）を $`-1`$ で初期化して

```math
\begin{aligned}
U_i &= (r{+}1,\ i{-}1,\ 0) +\!\!+ \mathrm{body}(\beta_i,\ r{+}2,\ i), & r &:= r+2
  &&(\beta_i \ge 1)\cr
U_i &= (r{+}1,\ i{-}1,\ 0) +\!\!+ (r{+}2,\ i,\ 0)
  &&&&(\beta_i = 0,\ \beta_{i-1} \ge 1)\cr
U_i &= (x_t{+}1,\ i,\ 0)
  &&&&(\beta_i = \beta_{i-1} = 0,\ \text{直前列} = (x_t, i{-}1, 0))
\end{aligned}
```

### 根と乗算ユニット（乗法）

$`1 + \beta' = \beta`$、$`\beta' = \omega^{\gamma_1} + \cdots + \omega^{\gamma_k}`$ として

```math
\mathrm{body}(\beta,\ x_0,\ y) = \underbrace{(x_0,\ y,\ 1)}_{\text{根}}
  +\!\!+ \big[\, \underbrace{(x_0{+}1,\ y,\ 1)}_{\text{桁}}
  +\!\!+ \mathrm{B}(\gamma_j,\ x_0{+}2) \,\big]_{j=1}^{k} .
```

### OT 埋め込み（冪・崩壊）

$`\gamma`$ を Buchholz の順序数表記の項として読み、そのまま列に写す。
加算項 $`\omega^\delta`$ ごとに $`\psi_0`$ ノード $`(x,0,0)`$ を置き、
その行 0 子として引数 $`\mathrm{arg}(\delta)`$ を書く:

```math
\mathrm{B}(\gamma,\ x) = \big[\, (x,\ 0,\ 0)
  +\!\!+ \mathrm{arg}(\delta_j,\ x{+}1) \,\big]_{j=1}^{k},
\qquad \gamma = \omega^{\delta_1} + \cdots + \omega^{\delta_k} .
```

```math
\mathrm{arg}(\delta,\ x) = \begin{cases}
\varepsilon & (\delta = 0)\cr
(x,\ 1,\ 0) +\!\!+ \mathrm{B}(\delta \ominus \varepsilon_0,\ x)
  & (\delta = \varepsilon_0 + \delta')\cr
\mathrm{B}(\delta,\ x) & (\text{otherwise})
\end{cases}
```

第 2 段が**逆崩壊**である。$`\delta \lt \varepsilon_0`$ では
$`\omega^\delta = \psi_0(\delta)`$ なので引数はそのまま $`\delta`$ を書けばよいが、
$`\delta \ge \varepsilon_0`$ では $`\omega^\delta`$ は $`\psi_0(\delta)`$ ではない。
$`\varepsilon_0 = \psi_0(\Omega_1)`$、
$`\varepsilon_0 \cdot \omega = \omega^{\varepsilon_0+1} = \psi_0(\Omega_1+1)`$ のように、
**引数の先頭の $`\varepsilon_0`$ を $`\Omega_1`$ の葉 $`(x,1,0)`$ に戻す**。
$`\delta \ominus \varepsilon_0`$ は先頭の $`\varepsilon_0`$ を 1 つ落とした残り。

### $`\alpha`$ が崩壊値 $`\psi_0(\Omega_X)`$ のとき

添字 $`X`$ の行列がそのまま入る:

```math
M(\psi_0(\Omega_X)) = (0,0,0)(1,1,1)(2,1,1) +\!\!+ \mathrm{shift}(M(X),\ 3).
```

**$`M(X)`$ のアンカーが、$`x`$ シフトされて $`\psi_0`$ ノード $`(3,0,0)`$ になる**
（アンカーと $`\psi_0`$ ノードは同じ列で、役目が二重になっている）。
$`X`$ の中身は $`x`$ をずらすだけで一切書き換えない。

例: $`M(\omega) = (0,0,0)(1,1,1)`$ なので
$`M(\psi_0(\Omega_\omega)) = (0,0,0)(1,1,1)(2,1,1)(3,0,0)(4,1,1)`$。
$`M(\omega^\omega) = (0,0,0)(1,1,1)(2,1,1)(3,0,0)`$ なので
$`M(\psi_0(\Omega_{\omega^\omega})) = (0,0,0)(1,1,1)(2,1,1)(3,0,0)(4,1,1)(5,1,1)(6,0,0)`$。

$`\alpha = \Omega_1`$ のときは $`\psi_0`$ を通さないので別扱いで、
$`M(\Omega_1) = (0,0,0)(1,1,1)(2,1,1)(3,1,0)`$。

## $`\Omega`$ の演算

ここまでは $`\alpha`$ の中に $`\Omega`$ が高々 1 個の原子として現れるだけだった。
$`\alpha`$ 自身が $`\Omega_v`$ の和・積・冪になる領域でも、**原子を 2 族に広げれば
上の文法がそのまま延びる**。実装は `tools/probe_eps_range.py`
（CLI は `tools/build_omega_alpha.py`）。

### 原子

| 原子 | 意味 |
|---|---|
| $`\Omega_v`$ | $`v`$ 番目の非可算基数 |
| $`\psi_v(X)`$ | 崩壊値（$`\varepsilon_0 = \psi_0(\Omega_1)`$ はその特殊ケース） |

どちらも $`x \mapsto \omega^x`$ の不動点なので CNF では分解できず、指数スロットの中で
1 個の記号として置かれる。$`\Omega_v \le \alpha \lt \Omega_{v+1}`$ となる $`v`$ を
$`\alpha`$ の**レベル** $`\mathrm{lvl}(\alpha)`$ と呼ぶ（先頭指数だけで決まる。
$`\alpha \lt \Omega_1`$ ならレベルは無い = 可算）。

### 土台 $`M(\Omega_v)`$

$`\alpha`$ が非可算のときは $`\psi_0`$ ノードが立たず、行列は
$`B = (0,0,0)(1,1,1)(2,1,1)(3,1,0) = M(\Omega_1)`$ を単位として作られる。
持ち上げ $`\mathrm{L}(x,y,z) = (x{+}1,\ y{+}1,\ z)`$ を使うと、**有限の $`v`$** では

```math
M(\Omega_v) = B +\!\!+ \mathrm{L}(B) +\!\!+ \mathrm{L}^2(B) +\!\!+ \cdots +\!\!+ \mathrm{L}^{v-1}(B)
```

すなわち基数の後続 1 段が持ち上げ 1 回に対応する。

一般の $`v`$ は $`M(v)`$ への**挿入**で作る。$`M(v)`$ を行 0 の森として読み、
**レベル列** = $`z = 0`$ かつ $`y \ge 1`$ の列のうち、行 0 親が

- 無いか z0 列（ただし親が根のアンカー以外の $`\psi_0`$ ノードなら除く = $`\Omega`$ 葉）、または
- z1 列であってそれが**根**（親が z0）であるもの（親が**桁**なら除く = $`\Omega`$ 葉）

を満たすもの、すなわちアンカーと $`{+}1`$ 標識と定める。すると

1. $`M(v)`$ の末尾列がレベル列ならそれを削除する。
2. 根のアンカーと残る各レベル列 $`c`$ の直下に、$`B`$ の尾
   $`(1,1,1)(2,1,1)(3,1,0)`$ を $`y`$ だけ $`c_y`$ 持ち上げて挿す。
3. 行 0 深さを $`x`$ として書き出す。

有限 $`v`$ でこれが上の閉じた形と一致することは機械検査している（$`v = 1,\dots,6`$）。
$`\alpha = \Omega_v`$ ちょうどのシート 132 行のうち **124 行が一致**する
（添字が入れ子の $`\Omega_{\Omega_{\Omega_\Omega}}`$ 等を含む）。

以下の規則 1〜10 が、$`\Omega_v`$ を含む一般の $`\alpha`$ の書き方である。

### 規則 1: 行 1 は行 0 の 1 段上のコピー

加算項 $`\omega^\delta`$ は **1 本の列**になり、その子が「残り」を綴る:

```math
\mathrm{strip}(\delta) = \begin{cases}
X + \psi_v(X)\cdot(c{-}1) + \rho & (\delta = \psi_v(X)\cdot c + \rho)\cr
\Omega_v\cdot(c{-}1) + \rho & (\delta = \Omega_v\cdot c + \rho)\cr
\delta & (\text{それ以外 — 吸収})
\end{cases}
```

第 1 段が上の**逆崩壊**（$`\mathrm{arg}`$）の一般形、第 2 段が新しい。
$`\delta \lt \Omega_1`$ なら列は $`\psi_0`$ ノード $`(x,0,0)`$、
$`\delta \ge \Omega_1`$ ならレベル $`v`$ の列で、これは
$`\omega^{\Omega_v + d} = \Omega_v \cdot \omega^{d}`$ を表す。
**$`1`$ の位置に $`\Omega_v`$ が入るだけで、行 0 と同じ構造が行 1 で繰り返す**。

例（$`\psi_0`$ の引数位置、$`x`$ から書く）:
$`\Omega`$ → $`(x,1,0)`$、$`\Omega\cdot2`$ → $`(x,1,0)(x,1,0)`$、
$`\Omega^2 = \omega^{\Omega\cdot2}`$ → $`(x,1,0)(x{+}1,1,0)`$、
$`\Omega^\Omega`$ → $`(x,1,0)(x{+}1,1,0)(x{+}2,1,0)`$。

### 規則 2: $`\alpha \ge \Omega_v`$ は $`M(\Omega_v)`$ の上に積む

```math
M(\alpha) = M(\Omega_v) +\!\!+ \big[\,U_1 +\!\!+ U_2 +\!\!+ \cdots\,\big]
\qquad (v = \mathrm{lvl}(\alpha),\ \alpha \neq \Omega_v)
```

加算ユニットの並べ方は上と同じで、初期状態だけ土台から取る。土台の**最後の根**
（= 行 0 親が z0 である最後の z1 列）を $`R`$ として、レベルは $`R_y`$、
最初のアンカーの $`x`$ は規則 7 で決まる。$`\alpha = \Omega_v`$ ちょうどのときは土台そのもの。

$`\Omega+\delta`$ が $`B`$ の直後に「橋」の $`\Omega`$ ユニットを挟むのはこの規則の帰結で、
特別扱いではない: $`\Omega+\delta`$ の第 1 加算ユニットが $`\omega^\Omega`$ だからである。

### 規則 3: レベルは番地であって $`y`$ の値ではない

列が名指すレベルは行 1 の数値ではなく **z0 祖先鎖の深さ**（番地）である。
文脈が鎖の頭 $`1+k`$ 列を既に与えているので、$`\Omega_v`$ を書くときは
$`M(v)`$ の残り $`M(v)[1+k:]`$ だけを書けばよい
（$`k`$ = アンカーの階段が $`M(v)`$ と一致する長さ）。
文脈が別の用途に使った $`d-k`$ 段だけコピーが深く入るので、
**ユニットのレベルを追う行 1 値（z1 列とレベル列）だけ $`d-k`$ 持ち上げ**、
絶対レベルを名指す列（$`\Omega`$ 葉・$`\psi`$ ノード）は持ち上げない。

同じ $`\Omega_2`$ が文脈で書き分けられる:
$`\psi_0(\Omega_2)`$ の引数（$`d=0`$）では $`(x,1,0)(x{+}1,2,0)`$、
レベル 2 のユニットの中（$`d=2`$）では $`(x,2,0)`$ の 1 列だけ。

### 規則 4: ユニットの葉はレベルを名指すだけ（1 列）

ユニットの葉（桁の子として $`\Omega_v`$ を書く位置）は、深さに関係なく**必ず 1 列**で、
その行 1 値は $`M(v)`$ の**最終列の行 1 値** $`\mathrm{leaf\_y}(v)`$、行 2 は $`0`$。

| $`v`$ | $`M(v)`$ の最終列 | 葉 |
|---|---|---|
| $`1`$ | $`(1,1,0)`$ | $`(x,1,0)`$ |
| $`2`$ | $`(2,2,0)`$ | $`(x,2,0)`$ |
| $`\omega`$ | $`(1,1,1)`$ | $`(x,1,0)`$ |
| $`\omega+1`$ | $`(3,2,0)`$ | $`(x,2,0)`$ |
| $`\omega\cdot2`$ | $`(3,2,1)`$ | $`(x,2,0)`$ |
| $`\omega^2`$ | $`(2,1,1)`$ | $`(x,1,0)`$ |

崩壊の引数位置（$`\psi`$ 列の子）だけは規則 3 のまま $`M(v)`$ を綴る。
$`\psi_0(\Omega_\omega)`$ の引数では $`\Omega_\omega`$ が $`(x,1,1)`$ と書かれるのに、
ユニットの葉では $`(x,1,0)`$ になるのはこのためである。

### 規則 5: アップグレード効果（末尾の印）

規則 4 は $`\Omega_\omega`$ と $`\Omega_1`$ を区別できない（どちらも葉は $`(x,1,0)`$）。
シートはそれを**行列の末尾に印を足して**区別する。印は $`M(v)`$ の最後の z0 列より後ろ、
すなわち末尾の z1 列たち:

```math
\mathrm{suffix}(v) = M(v)[\,i{+}1:\,],\qquad i = \max\{\,j \mid M(v)[j]_z = 0\,\}
```

$`\mathrm{suffix}(\omega) = (1,1,1)`$、$`\mathrm{suffix}(\omega^2) = (1,1,1)(2,1,1)`$、
$`\mathrm{suffix}(\omega\cdot2) = (3,2,1)`$、
$`\mathrm{suffix}(1) = \mathrm{suffix}(\omega+1) = \varepsilon`$。

印が現れるのは、その葉が**行列の最終列であるとき**だけで、後ろに何か書かれると吸収される。
$`x`$ は、その行列内で同じ印がすでに立っている位置に合わせる。

```
M(Omega_w)         = M(Omega_1) ++ (1,1,1)
M(Omega_w + W)     = ...(7,1,0)                 印なし（最後の葉は Omega_1）
M(Omega_w * 2)     = ...(7,1,0)(1,1,1)          印あり（最後の葉が Omega_w）
M(Omega_w * 2 + 1) = ...(7,1,0)(6,3,0)(7,4,0)   +1 が続くので印は吸収される
```

これは Hexirp 氏のいう**アップグレード効果**の書き手側の姿である。

### 規則 6: 階（storey）— 梯子を敷き直す

極限レベルの領域では、葉が届く深さはその領域自身の葉の深さ $`\mathrm{leaf\_y}(v)`$ まで。
それを超えるレベルを名指すとき、また梯子を使い切ったときは、
**行列（直前の階）の持ち上げコピー**を 1 段挟む:

```math
\mathrm{storey}(C,\ y) = \mathrm{L}(C)\ \text{の最終列の行 1 値を } y \text{ にしたもの}
```

これはシートに実在する行そのもので、$`C = M(\beta)`$ のとき
$`C +\!\!+ \mathrm{storey}(C)`$ は $`\psi_0(\Omega_\beta + \psi_1(\Omega_\beta))`$ の行である。
$`\Omega_1`$ 領域の $`B +\!\!+ \mathrm{L}(B)`$ も、$`\Omega_\omega+\Omega`$ 領域の 26 列も
同じ形をしている。

階が要るきっかけは 4 つ:

| きっかけ | 例 |
|---|---|
| 葉が領域より深いレベルを名指す（1 段/レベル） | $`\Omega_\omega+\Omega_2`$、$`\Omega_\omega+\Omega_3`$ |
| 直前の葉が領域と同じ葉を使った後、次の加算ユニット | $`\Omega_\omega+\Omega+1`$ |
| 同じことがユニットの桁と桁の間で起きる | $`\Omega_\omega+\Omega\cdot\omega`$ |
| 同じことが桁の中の列と列の間で起きる | $`\Omega_\omega+\Omega^\Omega`$ |

2 段目以降の階は、行列全体ではなく**直前の階**を持ち上げる
（$`M(\Omega_v) = B +\!\!+ \mathrm{L}(B) +\!\!+ \mathrm{L}^2(B) \cdots`$ と同じ積み方）。
1 つの加算ユニットで敷いた階は、その加算ユニットが終わるまで使い回す。

### 規則 7: 次のアンカーの $`x`$ — 土台が葉で閉じているか

土台の最後の加算ユニットの根 $`R`$ の次に来るアンカーの $`x`$ は

```math
x = R_x + \begin{cases} 0 & (\text{土台の最終列が z0 の葉}) \cr 1 & (\text{印や桁で終わる}) \end{cases}
```

$`B`$（葉 $`(3,1,0)`$ で閉じる）では根と同じ $`x=1`$、
$`M(\Omega_\omega) = B +\!\!+ (1,1,1)`$（印で終わる）では $`x=2`$、
$`M(\Omega_{\omega^2}) = B +\!\!+ (1,1,1)(2,1,1)`$（桁で終わる）でも $`x=2`$。

### 規則 8: 添字が非可算なら、レベルは土台のコピーで名指す

$`v`$ 自身が非可算（$`\Omega_\Omega`$、$`\Omega_{\Omega_\omega}`$ 等）のとき、
最初の加算ユニットの代わりに**土台の最後の階のコピー**を置く
（末尾の印を落とし、$`x`$ をアンカー位置へ、行 1 値を $`{+}1`$、最終葉は名指すレベルのまま）。
そのあとは普通のユニットが続く。

```
M(W_{W+1}) = M(W_W) ++ copy ++ [ユニット] ++ [+1 ユニット]
             |7 列|   |7 列|
```

階を跨いだあとは、領域自身のレベルを名指す葉は**そのユニットのアンカーと同じ行 1 値**を取る
（跨ぐ前は $`\mathrm{leaf\_y}(v)`$）。アップグレードの印も、階のぶん持ち上がった
コピーの位置に置く。

### 規則 9: $`\psi_{\Omega_u}(X)`$ は崩壊なのでユニットを作らない

添字が基数そのもので書かれた崩壊 $`\psi_{\Omega_u}(X)`$ は $`\Omega_u`$ の**直下**に来る
（添字が順序数の $`\psi_u`$ が $`\Omega_u`$ の直上に来るのと逆）。行列も新しいユニットを
作らず、$`M(\Omega_u)`$ の**最終葉の行 1 値を 1 下げ**（これが崩壊の印）、
その下に引数を綴る:

```math
M(\psi_{\Omega_u}(X)) = M(\Omega_u)^{\downarrow} +\!\!+ \mathrm{write\_level}(\mathrm{lvl}(X),\ x,\ y_0{-}1)
```

$`y_0`$ = 元の葉の行 1 値。引数が添字自身なら 1 列 $`(x,y_0,0)`$ で済む。

### 規則 10: 梯子の被覆は「文脈の行列との共通接頭辞の中の最深レベル列」

規則 3 の $`k`$（文脈が $`M(v)`$ の頭をどこまでくれるか）は次のように数える。
候補の梯子行列 — アンカーの階段 $`M(d)`$、いま書いている行列そのもの、
$`\psi_{\Omega_u}`$ の中なら $`M(u)`$ — それぞれと $`M(v)`$ の**共通接頭辞**を取り、
その中の**最深のレベル列**（行 1 値が $`d`$ 以下のもの）までが覆われている、と数える
（候補のうち最大を採り、深さ $`d`$ で頭打ち）。

同じ $`M(\omega\cdot2)`$ でも、$`\psi_{\Omega_{\omega+1}}`$ の中（梯子 $`M(\omega{+}1)`$）
では覆われて残り 1 列、$`\psi_1`$ の中（梯子は階段 $`M(1)`$ と手前の行列）では
覆われず $`M(\omega\cdot2)[1:]`$ 全体を 1 段持ち上げて書く。

シートの純粋 $`\psi_0(\Omega_\alpha)`$ 行 813 行のうち、yaBMS の `bms -s` で
**シートの行列自体が標準形でない 28 行**を外した 785 行が測定対象:
